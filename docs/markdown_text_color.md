# Markdown 字体颜色

选中可编辑的 Markdown 文字，右键选择 **字体颜色…**，再点常用色或输入自定义颜色。也可以点击色块打开系统颜色选择器。**恢复默认颜色** 去掉选区内由此功能添加的颜色；取消或按 `Esc` 保持正文不变。常用色支持方向键，所有控件支持 `Tab`。

颜色随文档保存。红色在白底上显示较深的红色，在夜间深色背景上自动调亮，保持原来的色系。切换主题只改变显示，不修改文档内容，也不会增加撤销记录。重新打开已经设色的文字时，面板会指示当前颜色；多种颜色的混合选区不预选单一颜色。

## R026

2026-09-13，用户要求在原生 Markdown 选区右键菜单加入类似 Word 的字体颜色，并自动适配日间、夜间主题。采用同色系亮度调整，不把红色机械反相成青色。

### 交互和边界

支持普通段落、标题、列表文字、表格单元格以及跨段落选择；保留加粗、斜体、链接地址和转义语义。行内代码必须完整选中，部分选中时给出说明并不修改正文。代码块、公式、图片、源码编辑器、只读内容和无选区状态不提供此编辑动作。

提供红、橙、黄、绿、青、蓝、紫、粉八个常用色及六位十六进制自定义颜色。非法颜色保持面板打开；取消不产生事务。打开时记录文档、活动标签、正文快照和原生选区；应用前再次核对。期间换了文档、内容变化、进入源码模式或锁定时拒绝旧操作，请用户重新选择，不能把颜色应用到另一篇文档。选区内混有无法安全映射的特殊语法时同样拒绝，保持原文。

### Markdown 存储

Markdown 本身没有通用字体颜色语法，使用 Typora 支持的标准行内 HTML，例如：

```html
<span style="color:var(--typora-code-color-b42318, #b42318)">重点文字</span>
```

CSS 变量名保存颜色身份，回退值保存用户选色。Typora 会过滤行内 HTML 的 class、id 和 data 属性，因此不依赖这些属性。重复改色、部分改色和恢复默认只处理本功能的规范标签，不清除用户手写 HTML 的其他属性或颜色。

支持行内 HTML 的外部阅读器可使用静态回退色；过滤 HTML／样式的平台可能只显示普通文字。日夜自动适配由 Typora Code 的原生阅读容器提供；独立的侧栏／历史只读预览保留原有 HTML 过滤边界，导出继续交给 Typora，不承诺其他阅读器或导出物具有同样的动态配色。

### 模块和原生事务

`markdown_color_menu` 只扩充原生菜单的一项，调用公共对话框和默认交互；保留原菜单节点、定位及已有动作。对话框尺寸受窗口约束，内容独立滚动，沿用公共4px控件圆角、焦点和清理机制。新的颜色网格是本功能的专用交互，不宣称它是 VS Code 或 Word 的完整菜单移植。

`markdown_color_native` 集中适配 Typora 1.14.10：`selection.buildUndo()` 记录选区，`UndoManager.buildReplaceUndo()` 取得局部节点快照，`exeCommand()` 应用替换／恢复光标，`undo.register()` 一次登记撤销、重做并接通 dirty 与宿主文档同步。表格通过同一事务内的 `buildAttrUndo(table, "userText")` 使原生源码缓存失效，撤销时恢复缓存和单元格。失败回滚局部节点。没有剪贴板中转、临时正文或整篇文档替换。

`markdown_text_color` 负责颜色校验、对比度和源文本区间改写。宿主隐藏的 Markdown 标记参与原文偏移映射，可见文字参与选区；代码、转义字符和 HTML 实体作为完整语法单元处理。只删除本功能的标签，其他语法字节保留。实际原生渲染与模型不一致时拒绝修改，不能猜测偏移。

### 明暗主题适配

`workspace_theme` 统一监听主题样式加载、根／body状态、窗口重新聚焦及系统明暗媒体查询；终端和字体颜色复用此机制。`markdown_color_theme` 只给原生阅读容器和颜色面板设置变量，合成祖先背景后求显示色；无关终端输出或列表变化不触发正文扫描。卸载恢复由本模块设置的变量和监听器，正文行内样式保持不变。

采用 W3C 的 sRGB 相对亮度和对比度计算。若所选颜色与当前纯色背景的对比度已经达到4.5:1，保持原色；否则在同一色系内向黑或白做最小调整，以4.5:1为普通文字目标。常用色是本功能显式定义的基础色，不是对截图颜色的估算。自定义颜色使用同一算法。图像／渐变背景、另有背景或强制文字样式的主题不能据此宣称整体符合无障碍标准。
