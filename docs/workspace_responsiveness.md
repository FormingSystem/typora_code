# R071 模块刷新隔离与仓库生命周期

## 问题与目标

2026-09-22用户反馈Git操作锁住全窗口，各模块刷新忙等待影响阅读；已有测试只覆盖准备好的仓库，漏掉空目录、初始化、嵌套仓库。已发现Git表单执行后仍占据全屏模态、工作树未跟踪合并二次复杂度、全量文件DOM渲染及父仓库复用遮蔽子仓库。

目标是让数据等待与操作锁只归所属控制器，渲染成本取决于可见内容，异步迟到不能写入新目录。确认/填写表单需要焦点时仍用公共弹窗，提交执行后释放遮罩；结果和进度回到Git区域。不取消已开始的写事务，不允许多个写入相互覆盖。

## 所有者与实现

- Git子进程继续异步运行；写锁只保护该仓库。提交前解析参数时可取消，真正执行后关闭表单并在原区域报告结果，其他模块可操作。
- 未跟踪文件合并使用路径集合；SCM变化行接入共享可视列表，列表服务拥有可见行、滚动/尺寸监听和销毁，领域拥有文件/目录数据、动作和折叠。所有结果保留可访问，不以静默截断减轻压力。
- 空目录提供清晰的未初始化状态和初始化入口，执行前再次检测仓库，初始化后重新加载；权限或Git缺失不能伪装为空目录。Git判定真实根，父/子控制器不得按路径包含直接混用。发现子仓库验证.git文件/目录所指真实仓库并报告扫描边界。
- 审计刷新订阅和同步IO，按实际热点处理。搜索/阅读/终端不共享Git忙碌标志；不建立统一全窗口等待锁，不把所有领域塞进同一调度器。

## 验收

单元：大数据合并复杂度、虚拟可视窗口、取消代际。功能：真实临时空目录、init、首次提交、删除.git、父子仓库、工作树.git文件、无效标记和权限错误；原实现必须被新增断言识别。系统：原始Typora大变更目录加载与刷新时持续操作非Git控件，记录心跳/长任务与DOM数量；20轮操作/切换、输入和未保存正文保持。数据规模与迭代次数分别记录，不用替身延迟冒充真实性能。安装与实际隔离卸载继续验收。

## 固定来源与性能范围

SCM行高依据 VS Code `88e44fa0e00b08f7758b4f6d05632e4fd5e4df6f` 的 `src/vs/workbench/contrib/scm/browser/scmViewPane.ts`：`ListDelegate.getHeight` 对资源行返回22，列表使用 `WorkbenchCompressibleAsyncDataTree`。本次沿用22px及现有颜色/图标，不复制上游实现；200行是本产品进入窗口化绘制的阈值，8行是预绘制余量，不称为VS Code配置。Graph文件行保留现有18px内容加4px间隔的22px步进。

共享可视列表由SCM变更、Graph详情和历史文件三处使用；路径树投影先组织层级，再按折叠状态生成行，排序不会把同一目录拆散。滚动/尺寸/折叠事件合并到一帧，销毁清理观察器和挂起帧。业务集合始终完整，组操作不只处理屏幕上的文件。

同宿主中指向同一真实根目录的多个Git视图共用写操作互斥；不同仓库可独立执行。等待读取的入口共用刷新任务完成通知，替代各自25/50ms定时轮询。首次项目配置改为异步文件读取。直接Git进程、目录发现均异步；发现关闭可取消，限额/错误有明确说明。

回归上限用于检测秒级阻塞，不能把低于上限理解为所有操作低于50ms。真实宿主记录大于50ms的采样及所处阶段；当前范围是本机、1万真实变更/5万模型行与20轮刷新，并未证明任意规模、网络磁盘和其他平台都无卡顿。

## R071.1 VS Code交互与空仓展示复核（2026-09-22）

用户进一步明确操作与界面以VS Code为准。复核发现空仓复用了无更改文本的0.6透明度，初始化进度及失败信息在已隐藏的提交区域，切换分区设置还能露出空仓提交控件。状态修复由SCM视图统一拥有：初次读取、未初始化、读取失败、正常仓库四种呈现；后台刷新已有仓库时保留原列表。空仓只提供初始化及已有的子仓发现入口，失败展示原错误和重试，不能把权限/Git缺失当作可初始化。初始化失败仍可再试；进行中禁用重复操作，取消必要选择不写入。

固定来源：VS Code `645f29cc3176500b4b5762ba887cf2a7f0ffdf2c` 的 `extensions/git/package.json` 中 `viewsWelcome` 按扫描/空仓/Git缺失等条件呈现；`commands.ts` 的 `git.init(skipFolderPrompt)` 在已确定单目录时直接初始化；`repository.ts` 的进度使用 `ProgressLocation.SourceControl`，没有全屏执行遮罩。当前产品继续遵循本机Git的初始分支配置，不声称移植了尚不存在的VS Code `git.defaultBranchName` 设置。

欢迎页几何取 `88e44fa0e00b08f7758b4f6d05632e4fd5e4df6f` 的 `views.css`：横向20px、底部1em、子项上距1em、按钮容器满宽且最大300px；`viewPane.ts` 的按钮使用主题默认样式。初始化使用共同primary角色，发现及重试使用共同按钮；文字可换行、不整体调淡、不自画一套悬停。按钮字号12px、行高16px、内边距4px 8px取同版本 `button.css`；`primary` 原有语义角色补齐共同主题颜色，初始化和提交共用，禁用不触发悬停。进度固定在可见SCM标题范围；状态提示节点移交给当前显示区域，不维护两个错误副本。

验证覆盖慢初始化时其他控件真实鼠标/键盘可用、失败原文可见且按钮恢复、重试和实际Git初始化、读取错误不提供初始化、分区菜单状态变化、窄侧栏及明暗/缩放。使用本轮构建与安装卸载结果，旧版通过记录不替代本次验证。
