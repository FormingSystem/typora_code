The current web page is loaded based on [R069.11](#section_7afc6fb72553) as of 2026-09-22: It has been verified that Typora 1.14.10 uses an independent Chromium guest to load web pages normally; the following early iframe restrictions only apply to fallback hosts that do not provide a guest interface, and no longer represent the default behavior on native systems.

2026-09-22 users first authorized the search sidebar link preview, and then in R069.1 it was explicitly changed to an independent lower-left preview. The following is the current agreement; the independent preview retains the ability for regular links to click and jump to the web page, as well as to preview search results; the regular click for editable content is used for editing links, see [R067.2](navigation_history.en.md#section_0b0c3efcd220).

<a id="section_fc5c3ba0889e"></a>
## Interaction and boundary

- When the text of a link in the main content is selected or the cursor is placed on the link, the independent settings update the lower-left preview; R069.2 requires that this panel does not forcibly open the function sidebar, and does not open it due to hovering on the web. Right-clicking a link uses clear left-right split and top-bottom split entry points.
- Sidebar and split view share read-only presentation; the local Markdown rendering of the main content and the title is localized, and the source code is edited in a read-only editor; split view provides "Open source file" to enter a regular editable file. The preview does not create a separate saveable draft, and does not modify the source selection and main content.
- HTTP/HTTPS links open in isolated iframes within the host Chromium, allowing scripts to run but not granting same-origin, Node, form submission, popups, or top-level navigation. When a site refuses to be embedded, retry and default browser entry options are retained; web page HTML is not injected into the document content, and no guarantees are made regarding the full availability of websites requiring login, cookies, or special permissions.
- Local relative paths are resolved based on the directory of the file to which the link belongs; reference-style links use the host reference table; unsupported protocols, undefined links, and invalid targets are clearly indicated. It is prohibited to interpret web page links as local files.
- The independent link dock and the search result preview each have their own content; closing the automatic link preview does not change the hit preview below the search.
- When a new link is selected, the automatic preview is closed, the workspace is switched, and when destroyed, the old iframe is removed and the late results are rejected. The split view target remains independent and is not automatically replaced with the main content selection.
