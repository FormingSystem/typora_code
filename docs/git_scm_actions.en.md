# Source Code Management and Graph Operations

The Source Code Management sidebar is divided into **Repository, Changes, and Commit Graph**. Right-clicking on the 'More' in the sidebar title or on any partition title allows you to check the partitions you want to display; at least one partition must be retained. The Repository area displays the discovered/opened repositories. Clicking switches the view, and the current row provides branch, sync status, and Git operations.

The Commit Graph toolbar, from left to right, is **Reference Range, Locate Current Commit, Get All Remote, Pull, Push/Release, Refresh, More**. The Reference Range supports search, all, automatic, and multiple branches/labels; 'Automatic' includes the current branch, upstream, and verifiable baseline references. Locating the current commit will adjust the filter if necessary, and then scroll to HEAD.

Right-clicking the toolbar button can hide the button, show other buttons, or configure keyboard shortcuts. Actions that are hidden and actions that cannot fit in the narrow sidebar can be executed from 'More'; 'Restore Toolbar' restores buttons that were manually hidden. The 'More' menu can also switch between **List/Tree** and open the full commit graph in the editing area. Keyboard shortcuts only take effect in the Source Code Management area, and input boxes and dialogues retain their original key presses.

Right-clicking a file can open changes, the current file, or the read-only HEAD version, and also perform stage, unstage, discard, add ignore rules, and locate the file. For new files without a HEAD version, the corresponding entry is disabled; renaming uses the original path in HEAD. Adding ignore rules to tracked files does not cancel Git tracking.

Right-clicking a commit can open all changes or open the hosted web page on the remote platform (GitHub, Gitee, GitLab, Bitbucket) based on the remote platform's identification. It can switch associated branches/remote references, detach HEAD, create branches or tags, delete associated branches, pick commits, compare upstream/baseline/specified references, and copy the full commit message or hash. Comparison uses fixed Git objects; when there is no upstream or baseline, the corresponding comparison is disabled. Other existing Git operations are retained in the sub-menu.

In the 'More → Worktree' of the Repository, you can list and open worktrees, open them in a new window, create or remove worktrees. Creating/Removing is similar to other Git write operations; first fill in the options and preview, then confirm the execution. Removing is protected for the main worktree, current worktree, locked directories, and directories with changes. Forced deletion is not used. The actual failure reason is displayed in the operation result. Canceling or switching to another repository does not execute the old plan.
