# R086 转到菜单与行列定位

2026-10-05：用户授权新增Go菜单，接入已存在导航，并以Ctrl+G打开VS Code式行列定位。保留原生菜单及主题；不由截图引入尚无服务的工作区符号、问题或编辑历史功能。

## 来源及交互

核对固定VS Code 6807068：editor/contrib/quickAccess/browser/gotoLineQuickAccess.ts、workbench/contrib/codeEditor/browser/quickaccess/gotoLineQuickAccess.ts。Windows Ctrl+G打开冒号前缀输入，提示当前总行数；支持行和可选列（冒号/逗号/#）、负数倒数、边界裁剪，Tab按可见列换算。沿用已有quick-open的600px上方居中容器、输入框和选中行，以及公共主题、焦点和退出服务。字符偏移及组合键拆分不在本轮范围。

Enter或单击提示确认；无有效数字不跳转。代码/源码输入期间只滚动预览，不移动光标、不写历史；Esc恢复打开前滚动及焦点。原生Markdown渲染视图用原生源码行映射，在确认时定位，避免预览输入改写原生选区；空行/隐藏语法按原生可呈现块定位，不把屏幕行当源码行。模型变化、关闭、切文档/工作区取消，不恢复到另一个文件。终端、浮动预览、其他输入框/模态以及输入法组合保留自身键位。Ctrl+G本轮明确授权覆盖其编辑器区域的同键旧行为；不改用户快捷键配置。

## 职责与菜单

导航端口提供所属编辑器的行定位会话，源文件、原生源码和Git源码比较各自捕获模型、版本、滚动与活动实例；共享UI只解析输入、调用预览/恢复/确认。确认前后通知现有导航历史，不新建历史栈。Markdown渲染通过已有原生定位服务；不打开磁盘文件覆盖未保存文本。只读渲染比较尚无精确列模型时禁用行定位，已有后退/前进保留。

Go复用已存在的导航历史、快速文件选择、编辑器切换和源码语言导航。菜单及快捷键共同调用命令，启用状态来自当前活动实例；菜单打开后目标变化拒绝旧动作。新增Go位于视图之后，使用既有共同菜单列和溢出机制，保留其他菜单顺序。

## 验收

单元覆盖行列、Tab、负数、边界、非法输入和大文本；真实Chromium覆盖即时预览/Enter/Esc、失焦、切文档、模型变化、分栏、只读、输入法、终端、菜单及动态状态。原始Typora验证可信Ctrl+G、当前内存源码与原生Markdown、导航后退、未保存正文不变。四主题、窄窗、缩放采用现有几何回归。最终构建、检查、隔离安装卸载与本机交付分别记录，未验证能力不称完成。
