# R067 编辑器导航历史

2026-09-21：修复 Alt＋左右键遗漏链接起点、源码位置和跨编辑器导航。历史属于当前窗口及工作区，正文、源码、大纲、搜索与顶栏按钮复用一个状态所有者；不新增第二套导航面板。

## 上游依据与配置

固定 VS Code 1.137.0（`645f29cc3176500b4b5762ba887cf2a7f0ffdf2c`）：

- `src/vs/workbench/browser/parts/editor/editorActions.ts`：Windows Alt＋Left/Right 分别执行 `workbench.action.navigateBack` / `navigateForward`，使用无过滤历史，不是最近文件列表或撤销正文。
- `src/vs/workbench/browser/workbench.contribution.ts`：`workbench.editor.navigationScope` 默认 `default`，跨编辑器和编辑组；另有 `editorGroup`、`editor`。本次采用默认跨组行为，不新增范围设置界面。恢复文件视图的 `restoreViewState` 与导航历史不同。
- `src/vs/workbench/services/history/browser/historyService.ts`：导航栈最多50项，恢复不新增记录；新跳转截断前进分支，近邻光标移动替换当前项；显式导航保留近邻位置。
- `src/vs/workbench/browser/parts/editor/textEditor.ts`：同一源码行视为相同位置，普通移动不足10行视为近邻；明确导航跨行时仍入栈。渲染Markdown没有一一对应的屏幕行，使用原生块光标及阅读锚点保存位置，不猜测屏幕像素为源码行。

上述文件均位于固定提交的 [VS Code 源码](https://github.com/microsoft/vscode/tree/645f29cc3176500b4b5762ba887cf2a7f0ffdf2c/src/vs/workbench)。不引入 VS Code 私有代码；独立实现符合宿主能力的适配。

## 事务与职责

`reading_history` 管理记录、去重、容量、前进分支和恢复索引。`reading_navigation` 管理唯一导航命令、Markdown原生入口、生命周期和取消。源码编辑器通过公共端口提供捕获与恢复，保存行列、选区、滚动及编辑组身份，不访问Markdown缓存冒充源码状态。

链接必须在原生改变选区或打开目标前捕获来源；同文件标题、跨文件标题均在目标定位结束后记录一次。不以文件打开中间态替代目标，不以只监听光标变化推断所有跳转。兼容宿主真实链接方法及其内部入口，保留外部URL原有行为。大纲点击使用同一出发点保护。

普通源码光标移动按10行阈值合并，明确的API定位保留近邻跨行位置；Markdown选区按原生块区分，块内移动更新当前位置，纯滚轮不灌入历史。后退/前进期间屏蔽由恢复触发的选区与文件事件。失效文件、取消打开或定位失败不提交新历史；工作区切换中断旧事务并清空旧位置。返回之后新跳转清除旧前进项；重命名迁移路径，关闭标签后允许重新打开磁盘目标。

## 视图分类与新增接入契约

2026-09-23用户要求统一归类，防止后续功能各自维护主题和导航。分类依据视图所属的交互容器与资源身份，不以可写性、文件后缀或渲染技术判断。

| 分类 | 实例 | 历史与快捷键所有者 | 视图必须提供 |
| --- | --- | --- | --- |
| 主编辑区资源视图 | 原生Markdown、源码、Git单版本、差异比较 | 窗口唯一导航服务，默认跨编辑组；Alt左右与主顶栏共用 | 资源与版本身份、组实例、捕获/恢复位置，必要时由原服务重开 |
| 独立预览会话 | 搜索、选中链接、目录预览及内部网页 | 预览会话自己的前后历史；焦点在预览时处理Alt左右 | 当前目标与位置、会话起点/清理、预览内跳转；打开原文件交给主文件服务 |
| 功能面板 | 设置、Git提交图、终端、搜索结果列表 | 自有业务选择/输入，不伪造文件导航记录 | 命令解析出资源后交给文件/编辑器服务；不复用正文位置 |

主编辑区资源视图新增前必须登记导航端口并声明持有的资源、版本、组及模式；导航栈只拥有顺序、容量、取消和命令，领域视图拥有选区/滚动/呈现状态和重开方式。只读、Shadow DOM和Monaco均不改变归类。恢复失败保留索引，切工作区释放旧身份，销毁注销端口；禁止新增另一套全局Alt监听或按路径后缀绕开服务。

所有Markdown阅读视图的视觉皮肤统一由`workspace_markdown_theme`适配，主题/样式失效通知统一订阅，布局与差异/命中颜色仍归领域；[R034.3](git_markdown_diff.md#r0343-当前主题继承2026-09-23)定义实际属性对照。新增验收至少串联来源→目标→打开原文件→后退/前进，覆盖入口图标/菜单/快捷键、关闭重开、主题变化和资源清理，不能仅验收单视图按钮。

## 验收

### R067.1 Git与只读编辑器导航（2026-09-23）

用户指出从Git渲染比较打开源文件后无法Alt后退。默认导航范围应覆盖编辑器身份，而非只按本地文件扩展名分类。固定上游`historyService.ts`以EditorInput/编辑组维护导航，`workbench.editor.navigationScope=default`覆盖所有编辑组；本项目继续采用该默认语义。

`reading_navigation_ports`按编辑器种类登记捕获/恢复端口；源码、Git差异及历史阅读各自拥有视图状态，唯一`reading_history`负责顺序与快捷键。Git身份包含仓库、比较/版本URI与原组实例，不能把左右两版本折叠成同一工作树路径。打开源文件前保存当前比较的模式、滚动和源码选区；返回优先激活原标签，已关闭则通过所属Git入口恢复只读快照，不覆盖工作树或未保存正文。恢复期间不新增历史，失败/取消不移动索引，切工作区清空历史并拒绝旧请求。关闭后的快照由最多50项的窗口历史引用，退出/清空后释放。

浮动链接预览内部仍保留独立历史；独立预览不向正文灌入每次链接跳转。Git差异和Git历史是主编辑区标签，必须进入主导航。验收覆盖打开源文件图标、菜单、Alt键和主顶栏箭头，Markdown/源码、渲染/源码差异、历史版本、同文件不同版本、跨组、关闭重开及失败取消。

回归发现：导航触发的会话保存即使文件列表和活动标签完全相同，也反复原子替换同一文件；Windows完整检查两次出现EPERM。会话存储先比较现有字节，相同则不创建临时文件；不同仍使用原原子事务，真实权限/占用错误不吞掉，不删除旧文件绕过错误。增加1000次不变事件仅一次替换和实际变化仍写入的验证；这不宣称处理了所有Windows占用情况。

单元覆盖去重、近邻/显式跳转、50项上限、回退后分叉、异常与旧异步结果。Electron功能覆盖实际键盘、内部链接入口、同文和跨文锚点、工具栏共用状态及销毁恢复。原始Typora临时文档覆盖原生链接起终点、连续回退/前进、源码与Markdown互跳、分栏和关闭重开；验证正文摘要与未保存状态，记录实际执行数量和宿主边界。安装使用标准事务，运行窗口仍需手动重启。

## 内容视图与来源关联

2026-09-24 R034.4：新增文件阅读、版本阅读或差异视图时，内容所有者必须保留结构化资源身份；差异还包括仓库、两侧版本、文件及改名前路径。列表展开状态、键盘焦点、当前内容来源分别归类，不能用最后点击的行、展示标题或文件名推断当前内容。切换活动视图通过既有事件投影选中，刷新/虚拟行创建读取同一来源，不在滚动时扫描正文或全量重绘。

“定位来源”只展开、滚动和聚焦来源列表，不重新打开文件或修改主导航历史；不存在的来源明确反馈，切换目标/工作区后迟到结果取消。功能列表与正文失焦后仍能展示非活动选中，焦点轮廓与选中底色独立；具体Git入口、精确比较身份及验收见[差异来源设计](git_markdown_diff.md#r0344-差异来源身份选中与定位)。此条是新增关联功能的接入约束，已有领域的来源类型由其所有者适配，不把普通文件与Git版本视为同一个资源。
