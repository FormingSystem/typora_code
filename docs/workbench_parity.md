状态提示为空时不占位；出现错误及取消重命名后，当前操作行仍须可见。边距沿用原存储字段，只恢复正文宽度控件，不重新应用历史字体或其他外观参数。

差异编辑器默认启用“空间不足时使用内联视图”，按该编辑组内实际差异编辑器宽度切换：不超过900 CSS px时内联，超过900 CSS px时左右并排。手动内联与自动切换是独立选项；手动内联在宽组中仍保持内联。默认左右分栏比例0.5只控制两个版本各占多少空间，不是自动切换阈值。更多菜单集中隐藏未修改区域、显示移动代码块和无障碍差异查看器；`F7`／`Shift + F7`进入并向后／向前阅读无障碍差异，普通前后改动使用标签行箭头。

## 必须保留的安全回归

搜索单击不切中央文件，双击按结构化路径和范围定位；源码与Markdown保留草稿、撤销、阅读位置、编码行尾及外部冲突保护。原生异步切换不能保存错文件。Git操作只在隔离临时目录验证，并核对文件与索引；普通查询不写Git对象。启动检查静态样式、单次初始化和资源清理。

当前发布为29个受清单管理的资产，head先加载两份CSS，再defer启动核心和工作台。schema 4安装与恢复预检、备份、校验和回滚；`native_profile`仅管理`framelessWindow=true`并保留其他设置，未知编码或并发摘要变化拒绝写入。安装不修改`app.asar`，不向打开的工程写配置；退休资产按精确清单备份和恢复。命令见[安装与备份](../enhancements/README.md#1.3_PowerShell单独安装扩展与备份)。

物理键盘与原生accelerator冲突尚未实证；合成按键不能替代这一层。Windows／兼容shell中的部署检查不代表原生Linux、UCRT64或ARM64设备验收。

## 本轮新增授权及验证边界

C/C++大纲只使用本机clangd；JavaScript、TypeScript、Python、CMake、YAML使用随包离线Tree-sitter，Markdown使用标题目录。clangd配置只保存在工作台用户数据中，可设置可执行文件、项目相对编译数据库目录与后备参数；详情见[代码大纲与解析环境](source_outline.md)。

恢复边距百分比、可见标题同步和中文链接提示属于已经落地的阅读修复。[大目录搜索](search_performance.md)现采用分批文件名结果、有界预读、Worker匹配和逐批结果渲染，保留忽略规则与替换安全边界。[左键拖动与独立窗口](drag_and_windows.md)标签使用原生拖放，同窗排序、跨窗合并和窗口外建窗；活动栏保留既有排序。实际移交经目标确认和来源身份复查。未保存原生Markdown与自动保存存在明确限制，完整撤销历史不跨进程迁移；隐藏夹具通过不替代原生双窗验证。
