# 操作指导设计

## R081 安装后引导（2026-09-27）

用户需要了解新增功能的位置、预览标签和快捷键变化。每次成功安装（包括同版本重装）后，下一次启动就绪且前台可见的 Typora 窗口自动显示一次引导；普通重启不重复。帮助菜单保留全部原生项目，新增“操作指导…”与“操作说明与快捷键…”。

引导用上一步、下一步、跳过、完成组织功能栏教学：顶栏、活动栏/资源管理器、标签、正文、搜索、Git、终端、设置及帮助。可见目标描边定位；关闭的面板指向其入口，不启动终端、不切换文件、不执行 Git、不修改用户工作区。目标不可见时给出明确说明并使用居中卡片。Esc、关闭及跳过均可退出并恢复原焦点。文档在新窗口打开，不替换未保存正文。

预览标签和缩放提供标为“操作示意”的轻量动画，支持暂停，尊重 prefers-reduced-motion；不下载视频或生成大型临时图像。其余操作在随安装包提供的 user_guide.md 中说明。

## 所有者与安装事务

标准 Windows/便携安装器在校验成功后写入 typora_code/installation.json（schema、install_id、sequence），纳入同一备份回滚事务。失败恢复原标识；每次成功重装产生新标识。标识不是发布资源摘要的一部分。卸载恢复/撤销沿用公开入口，不增加第二套部署。

工作台引导服务拥有命令与自动触发；状态服务在用户数据 settings/onboarding_state.json 只保存最近一次安装标识。固定短期锁文件避免多窗口同时消费，进程退出后可回收失效锁；不按版本堆积记录。仅启动时读取匹配已加载发行序号的安装标识，运行中的旧窗口不消费刚装的新版本。启动就绪、原生文件加载完成且无其他模态框时才尝试展示；关闭即释放监听器/观察器/动画/浮层。状态写入失败仅提示，不阻断工作台。缺失/无效安装标识不自动弹出，手动帮助仍可用。

UI 复用 workspace_dialog、公共按钮、焦点/退出栈和静态样式。独立引导视图仅拥有步骤与目标矩形，按 resize/scroll/目标尺寸变化合并一帧定位，不持续全局重绘。目标不可交互，教程不把底层点击转为业务操作。

## 源码参考与取舍

固定 VS Code 6807068 的 src/vs/workbench/contrib/onboarding/browser/media/spotlight.css 和 spotlight/spotlightOverlay.ts：采用聚光描边、320px 卡片、16px 内容间距、8px 操作间距、1.4 行高、视口内定位及减少动画约定。因 Typora 为可编辑文档宿主，复用现有模态焦点与退出机制，覆盖当前窗口而非运行上游的命令驱动步骤。目标定位额外保留安全边距，窄屏卡片可滚动；不更改正文、图标或原生菜单样式。

## 验收与边界

状态测试覆盖新装/同版本重装、已读、多窗口竞争、失效锁、失败回滚及不同加载序号。UI 验证实际帮助入口、前进/后退/跳过/完成、Esc/Tab/焦点恢复、所有步骤可见区域、目标缺失、缩放、明暗、窄窗与减少动画、销毁后无残留。原生宿主验证就绪自动显示与手动重看。安装候选必须通过安装→检查→两类卸载→重装及卸载失败用例，本机只读卸载预检后安装；不关闭用户窗口。跨平台未实测时保留边界，不以 Electron 替身声称原生全覆盖。
