# R068 代码块展开与高度隔离

2026-09-21：用户反馈展开长代码后其他短代码框异常增高，点击短框才恢复。目标是每个围栏独立展开，短代码始终按自身内容展示；保留当前阈值、按钮、打印、语法及原生编辑能力。

## 状态与职责

展开类和按钮属于单个围栏；内容、行高缓存和编辑状态属于该围栏的原生CodeMirror。展开/收起造成文档布局变化，不能把另一个块的缓存高度当作真实内容长度，不能全局复用高度或依赖用户点击才刷新。旧实现只刷新被操作围栏，其他实例的宽度与可见性变化未纳入测量生命周期；原生混排样本已确认存在陈旧行高缓存。

## 交互与实现边界

只调整高度测量/失效与生命周期，不增加另一套编辑器，不修改Markdown、焦点或选区。长代码展开与收起各自保持，图表继续走独立查看器。需要刷新时限定到实际受影响的实例并合并布局批次，关闭文档/销毁后不执行旧回调；不能用每帧全量刷新修正偶发显示。

## 验收

原始Typora混排多个长短围栏，先记录短块高度，展开/收起其他长块并滚动复查，无须点击短块即保持正确高度；覆盖不同缩放、未保存编辑及20轮操作，核对正文/光标/展开状态、异步清理。已有交互与缩略图回归、构建、分类测试、同候选安装卸载重装及本机安装一并记录，物理输入/其他平台边界单独说明。

## 原生复现与方案

文档副本在1.8缩放下复现：单行围栏doc.height缓存为115.21px，后续重测为23.04px；围栏没有其他块的展开类。展开/收起带来的布局及滚动暴露出原生CodeMirror换行/高度缓存失效，短行数量本身不能决定显示高度（长行可能正常换行）。使用生成的长短混排长文本重复此路径，不把用户正文写入测试库。

共同几何适配器按围栏登记原生实例：ResizeObserver只响应宽度变化；IntersectionObserver在进入可见区时刷新本实例；展开/收起明确请求当前围栏刷新。离屏实例保留待测量状态，帧内合并请求；刷新产生的高度变化不重新触发无限刷新。扫描仅负责登记/移除实际节点，窗口resize和字体加载使测量失效。实例替换/文档移除和工作台销毁释放观察器及待执行帧。不更改现有CSS尺寸、颜色或阈值，使用已核对的宿主CodeMirror.refresh接口，不按行数强设高度。

原生验收先等待私有桌面运行器完成窗口尺寸设置，再滚动创建宿主延迟初始化的编辑器。采样必须位于可见区域；不能把尺寸切换途中离屏实例的高度当作可见状态失败。原文副本可附加生成长代码作为控制样本，不修改原件、不将正文写入证据。

固定布局的旧版原文混排用例可通过；加入围栏宽度520/640px交替变化后，旧版在可见短块复现107.78px→61.86px。宽度仅由隔离夹具设置，用于模拟布局改变，不是产品新增尺寸。修复按实际宽度失效，保持正常换行所需高度。

2026.09.21.4构建、完整check、3组UI、原生20轮生成混排与10轮原文副本混排（共230次高度对照）通过；离屏、宽度变化、同节点编辑器替换与销毁回归通过。同候选安装/两种卸载/重装、65卸载断言通过；本机29资产匹配、check OK、卸载预检detach，用户窗口未重启。证据见[代码块几何验证](../enhancements/tests/evidence/code_blocks_geometry_20260921.json)。原生使用renderer事件，其他平台和物理输入未测；不把安装等同当前窗口已加载。

## R068.1 围栏代码块一键复制

2026-09-22用户要求代码与纯文本围栏可一键复制。短块、无语言块和折叠长块采用相同入口。鼠标悬停或键盘进入时在块右上显示复制图标；点击立即复制，成功显示勾选反馈，失败显示可重试信息。只读Markdown预览采用同一行为；普通行内代码和网页内容不增加控件。

复制控制器仅拥有入口、反馈计时器及当前块的读取回调。原生正文点击时从该块当前CodeMirror实例getValue读取（包含未保存及折叠内容），只读预览从渲染后的pre/code读取；不读取行号、围栏或工具栏，不改选区、不触发保存。复用文件服务的copy剪贴板端口及文件剪贴板失效管理；失败保留内容且不降级为选中全文复制。预览复制呈现文本，沿用预览已有的换行/制表符规范化。

复用正文外媒体入口的定位、裁剪、键盘捕获和销毁机制，通过紧凑动作选项承载复制，不向宿主可编辑DOM插入按钮，不占正文流高度。块删除或重建时移除旧入口和计时器，销毁释放观察器和监听器。图表渲染继续由图表操作管理，不把图表SVG误作代码文本。

样式依据固定VS Code提交645f29cc3176500b4b5762ba887cf2a7f0ffdf2c的src/vs/base/browser/ui/actionbar/actionbar.css（Codicon 16px），复用本工程24px紧凑按钮及共享4px交互圆角；copy/check/warning使用现有官方Codicons。右上覆盖位置为本工程阅读适配值，不声称VS Code正文完全同构。

验证覆盖当前内存正文、空块、Unicode、制表符、长块全量复制、多个块互不影响、失败重试、键盘/鼠标、动态替换/销毁、明暗与缩放、原生正文/dirty/选区/高度保持及预览。功能压力采用100次复制，原生20次；共享媒体入口回归图片/图表，不用替身替代原生读值。交付记录实际构建、安装、隔离卸载重装及仍未覆盖平台。
