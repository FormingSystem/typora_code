# R034.1 Markdown渲染差异

## R034.3 当前主题继承（2026-09-23）

同日R069.10关联复查补充：:root默认变量与html/body主题变体的自定义变量按原条件共同进入Shadow，避免暗色主题标题沿用默认色。布局声明不从根变体复制，Git历史/比较继续复用同一主题适配器；当次证据见[预览固定与关联主题回归](../enhancements/tests/evidence/preview_pin_20260923.json)。

用户反馈渲染比较与所选主题不同。主题规则进入Shadow DOM后，正文从body继承的字体/颜色不会穿过工作台功能容器自动恢复；历史阅读器还存在独立的固定标题/表格样式。所有只读Markdown使用共同主题适配：复用当前有效主题规则及正文计算后的继承属性，禁用样式不参与，主题加载/切换由统一通知失效缓存。不在滚动时提取CSS，不重建阅读节点；各视图只拥有布局、定位标记及差异色。未知第三方编辑器DOM扩展不在本次兼容承诺内。

验证需比较原生正文与搜索/链接、Git历史、双栏比较的实际字体、字号、行高、标题/表格颜色，覆盖明暗主题、主题异步加载与禁用样式、切换主题后的阅读位置。差异红绿底色属于审阅语义，保留；验证不能只判断“左右颜色不同”便宣称主题相同。

2026-09-23用户要求：Markdown比较不能只有源码，需把左右版本排版后着色，直接聚焦可读内容。Markdown双版本比较默认进入渲染视图；同一顶栏用预览图标切换源码，统一差异设置保存偏好。普通源码文件及单版本阅读保持原行为。

## 交互和职责

比较身份、Git读取、错误和刷新继续由现有Git文档服务拥有；Monaco的异步差异结果是唯一变更范围来源。渲染视图不自行读工作树、保存文件或启动第二次Git扫描。按完整Markdown块映射源码行；未改块作为左右对齐锚点，变更块左红右绿，新增或删除侧留出对应空位。标题、列表、表格、引用和围栏保持结构；颜色之外显示删除/新增语义标签。工具栏前后变更及F7定位当前视图，打开原文件与整文件动作保留。选区暂存/撤销只在源码侧操作，渲染态明确禁用；查找切到源码定位，不能操作隐藏选区。

共用预览主题提取与代码/图表渲染，Shadow DOM隔离原生编辑增强。历史HTML净化，链接只呈现文字和目标，不自动打开外部页面；图片显示替代文字和地址，避免用当前图片冒充历史图片。Front Matter及不可见定义变化显示源码块，防止丢失变更。修改仅排版语法时仍标记所属块。当前阶段提供块级着色，不承诺逐词着色、完整Typora数学/HTML扩展或历史附件读取。

一次比较共用滚动容器，成对块按较高一侧对齐；窄视口仍保留左右两栏。切换模式保存各自滚动；刷新/切设置/关闭使用代际拒绝迟到渲染并释放图表资源。差异计算未完成显示等待；过大内容（两侧合计超过1MiB UTF-8或单侧超过10000个lexer token）保留源码视图并提示，不阻塞正文。格式化和DOM构建按批次让出线程，不扩大上一轮大仓库内存路径。

## R034.4 差异来源身份、选中与定位

2026-09-24：差异页拥有仓库、左右版本、文件及旧路径的结构化来源，不从标题或当前提交展开状态反推。源码和Markdown渲染比较共用该身份；侧栏与中央Git文件行只投影当前活动差异来源，切标签、刷新或虚拟行重建重新计算，普通文档不保留过期差异选中。展开、键盘焦点与当前比较文件分别管理，焦点离开列表保留非活动选中，悬停不覆盖选中。

面包屑类型入口左侧增加官方target图标“定位当前Git差异来源”。点击显示源码管理，展开对应提交及祖先目录、滚动并聚焦目标文件，不改变差异正文。历史不在当前页/筛选中时定向加载该提交，保留原筛选及其他记录；失败原文展示，缺失目标不伪造成功。暂存与未暂存比较定位对应变更组；任意基线到工作树的合并比较不冒充某个暂存组，当前尚无精确对应行时明确提示；改名按新路径定位并保留旧路径。切库、切换活动差异或销毁后迟到定位失效，重复请求只执行最新一次。

VS Code依据：固定1.137.0的scmHistoryViewPane.ts revealCurrentHistoryItem使用tree.reveal、setSelection和setFocus并在缺失时加载目标；共享listColors的活动/非活动选择与focusBorder分别管理。采用当前Light Modern/Dark Modern主题颜色角色，保留22px Git行与16px官方target图标、24px动作按钮；定位当前差异的命令语义为本产品扩展，不冒充上游HEAD定位。

验证：相同文件不同提交、改名、分组及普通标签切换，关闭重开/刷新、树/列表/超过200项虚拟化、折叠/筛选目标、异步取消，明暗与焦点/悬停/键盘，原始宿主实际Git仓库。选择同步仅更新已绘制行，不扫描文件正文、不引入轮询或滚动时全量重建。

## R034.5 共享软换行与版本化默认值

2026-09-24：普通源码（包括C/C++）、Git源码比较、历史文本和源码预览复用文本呈现设置，默认wordWrap=on、diffWordWrap=on；只软折行，不插入换行或新逻辑行号。统一设置/编辑器和比较菜单写同一所有者，关闭后允许横向滚动。Markdown正文继续自然排版，渲染中的代码与表格遵循同一宽度策略。

本次配置契约以2026.09.24.3为迁移边界，只迁移软换行，不清空其他偏好。未安装过增强或旧契约配置首次加载时写入true及契约版本；同版本或更新契约保留有效用户值，卸载保留用户数据和该标记，重装不重新覆盖。失败不改正文，存储不可用时使用内存默认并反馈；不把整份配置重置当作默认迁移。

固定Monaco0.56 editorOptions的wordWrap=on按视口宽度排版、逻辑行保持原样；diffEditorOptions.diffWordWrap可覆盖两侧。上游默认off，本产品按用户要求采用on。StableEditorScrollState以首个可见模型位置及相对视口偏移恢复，禁止跨布局只复用scrollTop。

## R034.6 呈现切换的内容位置契约

同一内容在软换行开关、源码/渲染、并排/内联之间切换属于呈现转换，不能成为打开新内容。转换前采集当前可见源行、列、左右版本及块内位置；新布局建立后映射到同一模型/语义块，保留选择。不同布局不复用旧像素值；无精确对应（删行、复杂图表）退到最近存在的语义块，不能静默回文首。异步渲染以代次拒绝旧结果，用户滚动/输入优先于待恢复动作。导航保存快照仍由视图负责，与正文历史独立的浮动预览不接管此命令。

## R034.7 Markdown语义差异范围

块源范围不包含尾部空行，零长度插入以行间边界处理，避免新增段落把前一个未变标题一起染色。相同块作为锚点；表格和列表进一步比较行/项，保留语义容器，表格只着色实际改变的单元格；新增/删除项保持明确增删色。链接目标、格式及定义变化不得仅因可见文字相同被当作无变化。复杂HTML/无法可靠拆分的结构保留块级差异，不声称全部Markdown语义等价。概览和前后差异跳转使用实际变更节点，不能把无变更区域计入。

回归包含标题后新增、EOF/空行/CRLF、重复块、表格单元格/行插删、列表插删、代码/链接定义、源码与渲染来回滚动定位、20次快速切换、不同宽度/主题；原生宿主与安装卸载分别记录。

## R034.8 展开、焦点与单一来源选择

2026-09-24：父提交展开不代表内容选择，不能用aria-expanded或详情开关aria-pressed绘制持久选中背景。提交点击仍展开/折叠，键盘焦点保留公共焦点边框；当前diff文件行按R034.4来源身份保留唯一选中底色。侧栏历史和中央提交图共用此分类，切换差异、定位、失焦、重建及虚拟化不会额外选中祖先。没有活动diff时不得从上次展开反推文件选择。

固定VS Code 1.137.0 scmHistoryViewPane.ts的revealCurrentHistoryItem分别调用tree.reveal、setSelection([historyItemTreeElement])和setFocus；展开与选择分属树状态。本产品文件来源投影沿用既有服务，不新增点击状态所有者，不改变Ctrl多提交比较命令。回归实际计算背景、aria展开、键盘焦点和来源行数量。

样式合同：文件/提交行同为固定上游22px，文件继承工作台13px；目录每级8px取固定listService默认值。拓扑11px轨道保持，轨道和目录缩进仅作用于内容padding，不能缩短整行选中背景。普通与虚拟列表共用该边界；表格阅读列的4em最小宽度是本产品防止标签逐字竖排的适配值，并非VS Code常量。
