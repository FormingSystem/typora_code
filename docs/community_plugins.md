# R057 社区插件接入

2026-09-20，用户要求接入社区插件模块，便于使用其他插件。本次以已继承的 typora-community-plugin 2.10.15/v2 公共接口为兼容基线；不把另一套 obgnail 插件协议混称为通用兼容。最新授权覆盖此前停用社区扩展管理的约定。

## 行为与职责

2026-09-20用户进一步明确主次：先保证TyporaCode现有UI启动、显示与交互，再接入社区能力。接入保持基础工作台布局、尺寸和默认面板，入口按下文R060的最新授权调整；不能把社区工作台/设置壳整体恢复作为插件兼容的前提。命名整理只发生在自有实现和适配层，第三方公开ABI按真实调用保留。验收分别记录基础工作台和插件适配，插件失败不能替换、重新初始化或延迟显示基础UI。

继续由原生 Typora 图标启动现有工作台。工作台初始化完成后再加载用户已启用的扩展；插件不得成为基础界面启动的前置依赖。公开核心API通过上游 v2 Symbol 暴露同一核心实例，只是扩展ABI接入，不运行第二个社区核心、内置插件或工作区。现有标签、侧栏、Git、终端和原生编辑器仍由原服务拥有。

插件管理入口复用侧栏、共享按钮、焦点和销毁机制，配置使用共享对话框，分已安装与社区目录，支持搜索、安装、启停、设置、检查更新和卸载；安装完成默认停用，由用户明确启用执行。插件运行于Typora进程并拥有其权限，界面说明这一信任边界，不宣称沙箱隔离或保证任意插件不会修改UI。

插件服务是清单、启用状态、实例、安装位置和操作队列的唯一所有者。文件夹切换不自动扫描并运行仓库内插件，统一使用用户数据下的专属插件目录；不恢复知识库私有路径或每库插件覆盖规则。各窗口有各自实例，磁盘安装使用互斥和事务；配置与插件程序分开，卸载保留设置并明确反馈。

## API与实现

从固定社区源码恢复Plugin、PluginSettings、设置组件及插件常用公共导出，保留上游许可证和来源摘要。对外强制的类名、生命周期和Symbol保持上游形式；新增服务、字段和函数使用snake_case。Plugin的命令、事件、脚本、样式、设置页注册交给现有生命周期，异常初始化也清理已经登记的资源；单个插件失败不阻止其他插件和基础工作台。

管理界面与服务分离。社区列表和发行包取自明确的上游仓库和固定发行身份；网络请求有超时与体积限制。清单验证id、版本、最低核心版本、平台和路径。安装、更新先准备并验证完整候选，再切换目标目录，失败保留旧包；不先卸载旧插件再下载。本地包也走同一验证。任何路径、ZIP条目、符号链接或清单不通过时不执行代码。

插件是否启用只由专属配置管理；扫描不会启用新插件。启用/停用/更新串行，重复点击幂等；加载迟到、停用或销毁后不重新激活。插件CSS只在启用期间存在。更新已运行插件后以手动正常重启生效，避免多个窗口仍在执行被删除的模块；不自动关闭用户窗口。

原生偏好命令仍打开Typora偏好设置；左下齿轮按R060提供原生偏好与插件设置，社区管理为单独明确命令/侧栏入口。社区框架自身的Core升级不开放覆盖本工程核心，工作台自身继续通过R047更新。官方Typora升级按R056最新确认方式重新运行标准安装器，不增加启动器或自动修复服务。

## 验收与边界

单元层验证清单/路径/版本、启停串行、失败回滚与资源清理，20/100/1000档覆盖重复操作和迟到结果；功能层验证菜单、搜索、忙碌/错误/取消、设置注册、焦点、主题及开关状态；系统层在原始Typora独立副本安装并运行固定版本的真实社区插件，检查命令效果、停用清理、工作台单实例和草稿保持。网络和ZIP替身与真实上游下载分别记录，不能混称在线验收。

逐项记录API覆盖和插件实例；最低版本通过不等于所有第三方插件兼容。依赖未开放的社区内部服务、另一插件框架、未知原生接口的插件明确失败，不用空函数伪装成功。实际改动、检查、安装与原生验收结果按统一证据体系归档；当次验证和安装状态见反馈记录及测试证据，不把API导出数量当作所有插件兼容。

## 实施契约（2026-09-20）

初始入口为帮助菜单“社区插件…”，2026-09-20由R060下述入口约定替代。管理页支持已安装/社区目录搜索、ZIP系统文件选择、信任并启用、停用、设置、检查并更新和卸载。安装默认停用；切换或隐藏侧栏保留管理视图与唯一订阅，已授权的安装事务继续；销毁时释放界面订阅。工作台销毁中止网络并清理实例。

程序按包内容摘要保存于用户数据的community/packages/id/revision，plugins.json只原子发布选定版本和启用状态。更新保留正在使用的旧目录，各窗口保持自己的已加载版本并显示等待重启；停用/卸载通过文件通知传递至其他窗口。磁盘写操作复用进程退出自动释放的跨窗口管道互斥，避免崩溃留下永久锁文件。卸载取消登记、保留个人设置及旧包缓存，避免删除其他窗口仍引用的文件；当前没有自动清除旧包缓存。

Windows ZIP复用标准安全解压实现，插件模式要求根manifest.json/main.js，最多32MiB压缩包、128MiB展开、5000条目，拒绝越界路径、链接、设备名和重复条目。在线目录先固定GitHub提交，发行包核对插件id/repo/version，使用限定HTTPS主机、体积与超时。非Windows安装解压尚未验收，不声称跨平台安装完成。

公共构造ABI兼容ES5 Parent.apply与ES类继承；Plugin、PluginSettings、设置项、后处理器等导出同一核心。设置样式仅作用于插件设置窗口，不能改变工作台。失败onload和构造期已登记资源均清理；后处理器停用清除框架生成的按钮和预览。真实插件可任意调用宿主与文件系统，本工程不宣称可以阻止第三方同步死循环或自动撤销其任意正文修改。

已选真实验证样本：Codeblock Copy Button 1.2.0，仓库typora-community-plugin/typora-plugin-codeblock-copy-button，发行ZIP SHA256 `41b52347fa526d23a5554813762309d368f440486c163c93885137229b44e704`。另有自有公共API夹具覆盖设置保存、命令、底栏与失败清理；测试替身与实际社区包在证据中分别注明。依赖未开放的社区内部管理器或另一框架协议的插件不在兼容承诺内。

Windows高频状态写入遇到EPERM/EACCES/EBUSY时，在原子替换阶段每25ms重试，最多20次；始终保留旧配置，不先删除。持续拒绝向调用方报错并清除临时文件，原启用状态不变。1000轮实际临时文件系统测试曾复现EPERM，修复后分档和持续拒绝注入验证均通过。

程序完整性校验使用异步目录读取与流式摘要，不把最多128MiB包一次性同步读入renderer；每个文件的相对路径和字节纳入同一摘要。大包校验期间通过事件循环心跳回归响应性，结果仍须在执行插件前通过。
