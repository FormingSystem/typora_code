# R070 SSH远程工作区

## R070.7 当前窗口服务对象与资源选择（2026-09-23）

用户发现SSH模式的仓库管理混入本地历史和宿主缓存路径，且目录选择只能逐层进入。窗口只能服务当前本地工作区或一个SSH身份（主机、账号、端口和配置），资源管理器、搜索、Git及集成终端共用该对象。不同窗口可服务不同连接，保存的多主机/账号记录不受限制。本节覆盖R070.5允许同窗口显式混开其他SSH和本地终端的旧约定；切换对象必须走共同工作区事务，不能只创建另一个目标的终端。

Git历史按连接所有者隔离，本地历史不展示SSH缓存；远端展示真实POSIX路径，宿主物化路径仅供适配层使用。打开、添加、发现与后台仓库状态读取都校验当前所有者，断线不得回落本地Git。无仓库页的查找入口直接选目录后扫描；管理入口可查看/移除当前对象的记录。主动查找至少扫描一层子目录，自动发现深度为0不再使手动入口成为空操作；更深层次遵循已配置的扫描深度。扫描取消、切库和迟到结果不得写入新对象记录。

远程打开文件/文件夹复用一个选择器：路径框支持绝对远端路径和相对当前目录的路径；祖先面包屑可直接跳转；单击选择，双击或Enter进入目录，确认打开所选文件/文件夹，目录模式无选择时确认当前目录。路径输入文件时先定位父目录并选中该文件。上下方向键移动选择，Backspace返回上层，Esc取消。读取失败保留可恢复状态，取消不改变工作区。后台正文焦点恢复不能关闭该模态选择器。

打开文件夹的“打开本地文件夹”入口调用宿主系统目录选择器；取消继续保留SSH，成功选择后先保护草稿与正在执行的写入，再统一切根、结束旧终端并清理Git/搜索/导航，后续终端在本地启动。入口不把缓存根交给系统选择器作为默认路径。远端目录选择与Git发现不暗中改变当前窗口根。

固定VS Code提交`88e44fa0e00b08f7758b4f6d05632e4fd5e4df6f`的`src/vs/workbench/services/dialogs/browser/simpleFileDialog.ts`以scheme/authority区分资源，并以OpenLocalFolderCommand显式调用本地文件系统选择。本工程采用资源归属与显式本地入口，目录行选择/确认及祖先面包屑按本次用户要求复用现有共享控件；不宣称复制整个QuickPick或新增原生文件管理器。

验证覆盖真实远端临时空目录/嵌套仓库，旧历史混合记录、不同用户归属、目录/文件选择和原生本地选择端口；功能层注入慢读取/取消/切换，核对命令实际cwd与无本地回退。原始Typora验证统一切换及终端身份；独立安装卸载重装与本机安装分别留证，未覆盖平台如实记录。

2026-09-22：用户授权左侧远程入口，用SSH管理远程Markdown与项目，每个独立功能验证后提交并推送。用户指定测试主机从本机映射和OpenSSH配置确定；账户和凭据不写入版本控制。

## 上游与目标

以[VS Code Remote SSH官方操作](https://code.visualstudio.com/docs/remote/ssh)的连接主机、认证反馈、远程目录、编辑保存和断开为交互依据。它在远端运行服务，不把网络映射盘当作SSH；本项目同样通过SSH执行远程文件操作。固定工作台基线`645f29cc3176500b4b5762ba887cf2a7f0ffdf2c`的`remoteExplorer.ts`定义远程视图容器，图标使用固定Codicons的`src/icons/remote-explorer.svg`，字号、树行、菜单和按钮复用本工作台共同规则。

## 实施与交付次序

1. SSH连接、取消和诊断，远程目录浏览、文本读取/编辑/冲突保护保存；Markdown阅读与源码编辑，独立远端身份和草稿保护。先完成可用读写闭环并真实验证。
2. 远程项目操作继续接入相同连接服务：文件管理、终端和Git能力逐项核对现有所有者后实现。每项未实装的上游能力保持明确未完成，不以入口或首个读写测试冒充全部Remote SSH。

VS Code Server、扩展宿主、调试和完整端口转发并非本项目既有能力，不能宣称已支持。首个远端后端以Linux/Python3为验证环境；其他远程系统支持按实际适配与测试记录。

## 所有者与失败行为

- OpenSSH是认证、主机密钥和SSH配置的唯一所有者，保留用户`~/.ssh/config`、代理与密钥配置。首次主机确认通过认证提示明确展示；变更主机密钥不绕过。密码/口令仅经短生命周期认证管道传递，不进入命令行、持久化配置、远端源码或日志。
- 连接服务拥有一个SSH进程与请求代际、超时和取消；UI只订阅状态。远端Python进程按JSON请求处理路径，不将文件名拼接为Shell命令；不安装或启动后台常驻服务。
- 远程资源包含连接身份和POSIX路径，不能交给本地fs/Git/宿主打开。编辑器拥有当前正文及已读摘要；读写失败或断线不清空正文、不冒充已保存。
- 保存先核对基线摘要和真实文件身份，写同目录独占临时文件后原子替换；保留权限并清理失败临时文件。外部变化明确拒绝覆盖。检查与替换间仍存在非协作写入竞态，不声称跨进程CAS。
- 关闭、切换连接、退出与工作区切换先保护未保存内容；远程工具不能绕过现有统一保存/关闭服务。迟到结果不写入新连接或新标签。
- 连接参数只保存非机密部分。断开后可重连，不自动反复弹认证框。

## 首期操作与边界

左侧远程资源管理器中输入SSH配置别名或`user@hostname`，点击连接；已有Host别名作为输入建议，端口、密钥和代理沿用OpenSSH配置。主机指纹必须先核对，密码不保存。连接后从远端用户目录逐级打开项目目录，上一级/刷新始终操作当前远端。

点击文件打开独立文本编辑标签，Ctrl+S或保存按钮写入远端；UTF-8 BOM和编辑器行尾保留，不支持二进制或非UTF-8编辑。Markdown可切换共同只读预览；当前预览不加载图片、不跟随其中链接。新建采用排他创建，重名不会覆盖；删除仅针对打开的单个文件，明确永久删除，按已读版本拒绝删除外部修改。保存保留权限，文件所有权/ACL/扩展属性不保证沿用；首期不支持跨窗口移动、远程自动保存、会话恢复和远程本地历史，关闭仍保护内存草稿。

SSH模块复用公共侧栏、语义交互、Codicons/Seti、Monaco、阅读渲染及文档关闭服务。工具栏随可用宽度换行，沿用现有社区侧栏13px/35px标题角色和目录26px行，不声称VS Code Remote SSH界面像素等价。目录最多10000项，分批200项绘制，读取/保存上限16MiB，预览2MiB；超限反馈而不静默截断。
