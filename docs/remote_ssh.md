# R070 SSH远程工作区

2026-09-22：用户授权左侧远程入口，用SSH管理远程Markdown与项目，每个独立功能验证后提交并推送。用户指定测试主机从本机映射和OpenSSH配置确定；账户和凭据不写入版本控制。

## 上游与目标

以[VS Code Remote SSH官方操作](https://code.visualstudio.com/docs/remote/ssh)的连接主机、认证反馈、远程目录、编辑保存和断开为交互依据。它在远端运行服务，不把网络映射盘当作SSH；本项目同样通过SSH执行远程文件操作。固定工作台基线`88e44fa0e00b08f7758b4f6d05632e4fd5e4df6f`的`remoteExplorer.ts`定义远程视图容器，图标使用固定Codicons的`src/icons/remote-explorer.svg`，字号、树行、菜单和按钮复用本工作台共同规则。

## 实施与交付次序

1. SSH连接、取消和诊断，远程目录浏览、文本读取/编辑/冲突保护保存；Markdown阅读与源码编辑，独立远端身份和草稿保护。先完成可用读写闭环并真实验证。
2. 远程项目操作继续接入相同连接服务：文件管理、终端和Git能力逐项核对现有所有者后实现。每项未实装的上游能力保持明确未完成，不以入口或首个读写测试冒充全部Remote SSH。

VS Code Server、扩展宿主、调试和完整端口转发并非本项目既有能力，不能宣称已支持。首个远端后端以Linux/Python3为验证环境；其他远程系统支持按实际适配与测试记录。

## 所有者与失败行为

- OpenSSH是认证、主机密钥和SSH配置的唯一所有者，保留用户`~/.ssh/config`、代理与密钥配置。首次主机确认通过认证提示明确展示；变更主机密钥不绕过。密码/口令仅经短生命周期认证管道传递，不进入命令行、持久化配置、远端源码或日志。
- 连接服务拥有一个SSH进程与请求代际、超时和取消；UI只订阅状态。远端Python进程按JSON请求处理路径，不将文件名拼接为Shell命令；不安装或启动后台常驻服务。
- 远程资源包含连接身份和POSIX路径，不能交给本地fs/Git/宿主打开。编辑器拥有当前正文及已读摘要；读写失败或断线不清空正文、不冒充已保存。
- 保存先核对基线摘要和真实文件身份，写同目录独占临时文件后原子替换；保留权限并清理失败临时文件。外部变化明确拒绝覆盖。检查与替换间仍存在非协作写入竞态，不声称跨进程CAS。
- 关闭、切换连接、退出与工作区切换先保护未保存内容；远程工具不能绕过现有统一保存/关闭服务。迟到结果不写入新连接或新标签。
- 连接参数只保存非机密部分。断开后可重连，不自动反复弹认证框。

## 验收

单元覆盖地址/参数边界、JSON协议、请求取消、冲突与过期代际；功能覆盖真实本地SSH进程、认证管道、远程临时目录、UTF-8中文/空格/特殊文件名、读写回读和外部冲突；系统在独立Typora副本覆盖活动栏、连接/取消/失败、远程编辑和草稿保护、明暗/缩放。压力按20次连接或100次文件操作成本选择，记录实数。安装交付同时执行安装→检查→卸载→重装→检查，实际用户环境只做卸载只读预检。

## 首期操作与边界

左侧远程资源管理器中输入SSH配置别名或`user@hostname`，点击连接；已有Host别名作为输入建议，端口、密钥和代理沿用OpenSSH配置。主机指纹必须先核对，密码不保存。连接后从远端用户目录逐级打开项目目录，上一级/刷新始终操作当前远端。

点击文件打开独立文本编辑标签，Ctrl+S或保存按钮写入远端；UTF-8 BOM和编辑器行尾保留，不支持二进制或非UTF-8编辑。Markdown可切换共同只读预览；当前预览不加载图片、不跟随其中链接。新建采用排他创建，重名不会覆盖；删除仅针对打开的单个文件，明确永久删除，按已读版本拒绝删除外部修改。保存保留权限，文件所有权/ACL/扩展属性不保证沿用；首期不支持跨窗口移动、远程自动保存、会话恢复和远程本地历史，关闭仍保护内存草稿。

SSH模块复用公共侧栏、语义交互、Codicons/Seti、Monaco、阅读渲染及文档关闭服务。工具栏随可用宽度换行，沿用现有社区侧栏13px/35px标题角色和目录26px行，不声称VS Code Remote SSH界面像素等价。目录最多10000项，分批200项绘制，读取/保存上限16MiB，预览2MiB；超限反馈而不静默截断。
