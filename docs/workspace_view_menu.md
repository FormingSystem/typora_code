# 视图菜单状态与原生开关设计

R018，2026-09-12：用户反馈视图菜单没有勾选，状态栏/工具栏设置前后视觉相同。目标是菜单状态反映真正显示的界面，动作经现有所有者改变对应区域；菜单不另存一份布尔状态。

## 状态来源与职责

菜单每次打开读取原生Markdown源码/只读/专注/打字机状态、工作区侧栏及当前面板、原生状态栏和工具栏、终端协调器当前面板状态。复用菜单组件既有 `menuitemcheckbox`、`aria-checked` 及官方勾选图标；选中、未选中、禁用分别表达。共享状态及数据不归菜单UI所有。

状态栏和工具栏使用Typora 1.14.10已核对的 `ClientCommand.toggleStatusBar` 与 `toggleToolbar`，保留宿主持久化和跨窗口通知。查清其原生DOM、父容器和工作台CSS约束；若外层固定布局使原生开关无效，修正共同布局适配，不添加只改菜单勾选的旁路。工具栏属原生Markdown文档，非该视图时按实际能力禁用，不让后台Markdown格式操作施加到其他标签。

## 交互与验收

开关执行后关闭菜单，再打开应显示实际新状态；活动栏、快捷键或原生设置改变状态也同步反映。状态栏关闭时阅读区/终端释放底部空间；工具栏保持Typora原生浮动交互，显示时位于活动正文区域，不进入终端或状态栏；阅读区域不足时暂时隐藏，区域恢复后继续显示；原生正文与未保存草稿不变。失败/取消保留所有者状态，不乐观写入虚假勾选。

测试菜单的开/关/禁用状态、实际命令路由、窗口缩放、终端开关、不同标签和销毁后恢复。原生状态与DOM核对、隐藏Electron和原生隔离验证分别记录，不能以静态截图证明动作完成。
