# 底栏原生控件与浮层布局设计

需求：R012、R012.1、R013、R015。来源：2026-09-12 用户截图与补充反馈。

## R012 底栏浮层定位

### 问题与目标

终端展开后，底栏“最近目录”菜单只露阴影；点击图钉后，标题列表又出现在窗口右上角。两者为不同的原生控件：`#sidebar-files-menu` 属于底栏目录菜单，`#unpin-outline-btn` 经宿主 `hideSidebar()` / `showOutline()` 打开 `#toc-dropmenu`。当时目标是让原生浮层出现在实际底栏入口上方。后续R012.1取消底栏大纲操作；当前仅目录、字数详情、语言面板继续使用底栏定位。

已只读核对宿主 `appsrc/window/frame.js`、`style/window.css`、`style/base-control.css`：目录菜单随原容器移动到 footer，但 footer 的层叠级别为 4，低于终端面板的 100；原生浮动大纲固定在 `top:0; right:4px`，级别为 25。现有边距容器使用 inline-size containment，不能把嵌套浮层的坐标直接当作窗口坐标。

2026-09-12 原始 ASAR 隔离复现进一步确认：宿主为可用行设置 `li.show`，但本机 `base-control.css` 的显示选择器是 `#sidebar-files-menu li.show #ty-sidebar-footer .show`，无法匹配实际菜单层级，导致所有行仍为 `display:none`，只剩约 5px 的菜单边框和 padding。这也是“只露阴影”的独立原因。适配样式只恢复 `li.show` 的显示，不把未标记的不可用操作一并显示。

### 交互、职责与方案

- `workspace_footer` 继续拥有原生底栏节点的搬移与清理；底栏浮层几何适配器统一管理目录、字数详情和拼写面板的定位，避免同类菜单再次被终端遮住。
- 保留原 DOM 身份、原生内容生成、目录选择和关闭事件；不克隆菜单、不接管最近目录数据。大纲的原生节点继续保留，底栏入口按R012.1隐藏。
- 开启状态从宿主 class 与实际可见性读取。以入口按钮和底栏的实时矩形定位，优先按钮上方；尺寸受窗口边界与标题栏下沿限制，长内容内部滚动。只在有嵌套浮层打开时提升底栏层级；浮层高于终端、低于顶栏菜单与模态框。
- 监听窗口、侧栏、底栏和编辑根节点几何变化，合并到动画帧更新；读取实际定位原点以处理 containment，不缓存绝对屏幕坐标。侧栏收起后，目录菜单仍使用留在底栏的文件入口。
- 原生关闭、取消及失败行为保留；适配器不调用文件或终端服务。卸载解除观察和样式属性，原生节点恢复；不修改文档、草稿、终端会话和安装包。

### 验收与回归

隔离 Electron 使用生产底栏、终端面板及原生选择器规则，验证终端隐藏／展开／最大化、侧栏打开／关闭、窄窗口、长菜单与窗口缩放。检查浮层完整落在可视区、底部邻接入口、中心命中菜单而非终端；保留原生节点和事件，关闭／卸载不残留。截图仅作几何证据，不替代真实宿主点击验收。

## R013 字数统计居中

### 问题与方案

右下字数统计文字偏移。宿主 `#footer-word-count` 保留 `padding-bottom:8px`，并继承旧 30px 行高和负上下 margin；工作台已采用紧凑底栏，沿用这些值会使计数框与文字中心错位。

仅规范底栏字数按钮的盒模型：高度跟随底栏可用高度，清除旧负 margin 和单边底部 padding，采用对称水平内边距与 flex 居中，保持当前字号、文字、计数箭头及原生点击事件。源码／差异视图原有隐藏规则优先；不更改统计逻辑或全局 UI 字号。字数详情复用 R012 的浮层几何适配。

### 验收与边界

在终端开关、窄窗口、不同位数与 100%／125% 缩放检查文字及箭头在按钮内容盒内垂直居中、按钮在底栏内容盒内居中；字数点击仍调用原生处理。检查源码状态仍隐藏计数，且清理后恢复宿主样式。

## R019 边距百分比居中

2026-09-12 用户指出边距滑块旁“6%”位置偏低。已读取Typora 1.14.10 `lib.asar/bootstrape/css/bootstrap.css`，其中HTML `output`带有`padding-top:7px`。此前组件只定义宽度和字体，没有取消继承的表单内边距；单独将父容器flex居中不能让文字居中。

百分比输出采用R008.1共享文本规则清除margin/padding，并在原30px输出槽内居中。保留既有0–24%单侧边距公式、存储键、键盘range操作、失败恢复和窄底栏隐藏策略。验收0%、6%、24%，22px/30px底栏及100%/125%窗口缩放；验证滑块、输出、字数、语言在同一基线上，正文/草稿及设置字段不因布局变化而修改。

## R008.1 统一底栏布局契约

2026-09-12 用户要求不再逐个控件补丁式修复。底栏是共同的布局边界：提供`workspace-footer-group`、`workspace-footer-control`、`workspace-footer-text`三种可复用角色，分别负责布局组、可交互操作、文本。公共样式唯一管理垂直高度、盒模型、上下margin/padding、居中与文字行高，操作间距由组gap管理，统一清除宿主遗留的负横向margin；使用现有样式引用计数器安装和清理。原生适配器为已核对的节点声明角色并在卸载时恢复，自有组件在创建时声明角色。

Git分支/同步/提交图、文件动作、源代码按钮、边距滑块、字数、语言、源码/diff状态区域共同使用契约。独立模块只管理自身宽度、横向间隔、截断、图标、业务状态和命令；显隐仍由原生状态、`hidden`及响应式规则决定。弹出菜单不属于底栏行，不套用底栏高度规则。组件新增时复用角色，不能再依赖宿主通用label/output表单样式或新增偏移量补偿。

Typora实机还发现字数控件继承`margin-right:-8px`，导致与语言点击区域重叠；共享操作角色统一归零横向margin，回归同时检查区域不重叠。

原生节点身份和事件保持；不开第二份状态存储。共享规则先用宿主负margin、单边padding、label/output污染夹具验证，再验证实际Typora。一次矩阵覆盖同类控件、终端隐藏/展开/最大化、侧栏切换、源码/diff、明暗、缩放与窄窗口；在共同边界修正发现的问题，不用某一个截图通过替代整体校验。

## 2026-09-12 底栏重复缺陷复查

R012、R008.1、R015再次收到实际截图：侧栏收起时目录菜单只剩边框，底栏左右文字高低不齐，右侧语言入口在非悬停时缺失。此前共用盒模型及局部矩形断言没有覆盖此状态，不能以旧验收关闭新反馈。

本轮沿用共同布局和原生适配的所有权，先核对实际宿主DOM、继承样式、主题与显隐，再修复对应规则。菜单仍是独立浮层，不套底栏行的高度、行高和文字布局；左右操作文本使用一致字体及文字行盒；可用语言入口应在非悬停时可见，真实语言和可用性继续由宿主管理。保持原文、未保存草稿、目录历史、键盘操作和终端会话。

验收以当前原始Typora实例与完整生产样式为准：打开/关闭侧栏，文件树/大纲，终端隐藏/展开/最大化，同一主题和缩放，指针离开底栏。记录菜单内容及实际可见条目高度、文字Range矩形、计算字体/行高/opacity与命中目标；验证最近目录实际选择和语言菜单，禁止只比较外层矩形即宣称文字对齐。补充能先复现旧构建失败的回归，再同步最终构建、安装和证据。事实根因及验证结果在复现后补入本节。


已在同主题、120%缩放的原始1.14.10私有实例复现：大纲隐藏时菜单高度5.90px，切到文件树后213.71px；调用原生可用性刷新不改变前者。根因是把`active-tab-outline`镜像到整个搬移的文件操作组后，原生`.active-tab-outline .file-action-item{display:none!important}`同时隐藏菜单中已经带`show`的行。修复只为直接底栏行记录专有上下文，列表/树排序状态仍按原生类同步；独立目录菜单继续只显示宿主可用行。

语言节点实际存在，宿主`#footer-spell-check{opacity:0}`在底栏hover/菜单打开时才改为1。用户已明确要求当前文档激活期间持续可见，故原生适配只固定该入口的opacity；源码/diff所属状态、下载/错误图标、语言内容与菜单仍由原所有者决定。

正文主题下左右文本矩形中心相同，但此前`line-height:1`使12px标签裁剪15.7px文字；左侧源码按钮被宿主内联`display:block`覆盖，16px图标贴在25px内容盒上沿。公共规则改为继承同一底栏字体、自然文字行高，同时在普通块布局下也按内容居中；单图标使用块盒消除基线留白。该规则不强制修改宿主display，从而保留原生隐藏语义，不使用逐按钮top偏移补偿。


本次验收：新回归先在旧实现复现大纲上下文隐藏可用菜单行，再修复后通过底栏、边距、编辑器状态、diff共4个UI目标；构建和完整check通过。原始Typora1.14.10隔离实例通过14项，包含大纲显示/收起与文件树、菜单覆盖真实终端且条目可切换目录、语言在非悬停/关闭语言菜单/聚焦终端后持续显示、100%→120%→100%共享文字及图标几何。可见文本Range中心差最大0.24px，标签无裁剪，图标居中；当前缩放与大纲收起组合的菜单从5.90px恢复到217.88px。源码/diff归属、终端最大化、窄栏、125%缩放与生命周期由上述UI目标覆盖，未声称全部由实机覆盖。

原生事件和节点仍由宿主管理，测试原文、修改状态、文件摘要与运行终端PID保持。修复后菜单和常显语言截图已检查；当前文档的语言不再跟随hover/focus隐藏，切换活动文档/编辑器时仍使用原有状态归属。证据与安装见[反馈记录](feedback_review.md#2026-09-12-底栏目录菜单与语言常显复修)。
