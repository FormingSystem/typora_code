# 底栏原生浮层与字数布局设计

需求：R012、R013。来源：2026-09-12 用户截图与补充反馈。

## R012 底栏浮层定位

### 问题与目标

终端展开后，底栏“最近目录”菜单只露阴影；点击图钉后，标题列表又出现在窗口右上角。两者为不同的原生控件：`#sidebar-files-menu` 属于底栏目录菜单，`#unpin-outline-btn` 经宿主 `hideSidebar()` / `showOutline()` 打开 `#toc-dropmenu`。目标是让原生浮层始终出现在实际底栏入口上方，内容可见、可滚动、可点击。

已只读核对宿主 `appsrc/window/frame.js`、`style/window.css`、`style/base-control.css`：目录菜单随原容器移动到 footer，但 footer 的层叠级别为 4，低于终端面板的 100；原生浮动大纲固定在 `top:0; right:4px`，级别为 25。现有边距容器使用 inline-size containment，不能把嵌套浮层的坐标直接当作窗口坐标。

2026-09-12 原始 ASAR 隔离复现进一步确认：宿主为可用行设置 `li.show`，但本机 `base-control.css` 的显示选择器是 `#sidebar-files-menu li.show #ty-sidebar-footer .show`，无法匹配实际菜单层级，导致所有行仍为 `display:none`，只剩约 5px 的菜单边框和 padding。这也是“只露阴影”的独立原因。适配样式只恢复 `li.show` 的显示，不把未标记的不可用操作一并显示。

### 交互、职责与方案

- `workspace_footer` 继续拥有原生底栏节点的搬移与清理；新增底栏浮层几何适配器统一管理目录、大纲、字数详情和拼写面板的定位，避免同类菜单再次被终端遮住。
- 保留原 DOM 身份、原生内容生成、目录选择、固定／取消固定、标题跳转和关闭事件；不克隆菜单、不接管最近目录数据、不创建第二套大纲。
- 开启状态从宿主 class 与实际可见性读取。以入口按钮和底栏的实时矩形定位，优先按钮上方；尺寸受窗口边界与标题栏下沿限制，长内容内部滚动。只在有嵌套浮层打开时提升底栏层级；浮层高于终端、低于顶栏菜单与模态框。
- 监听窗口、侧栏、底栏和编辑根节点几何变化，合并到动画帧更新；读取实际定位原点以处理 containment，不缓存绝对屏幕坐标。图钉使侧栏收起后仍使用留在底栏的入口。
- 原生关闭、取消及失败行为保留；适配器不调用文件或终端服务。卸载解除观察和样式属性，原生节点恢复；不修改文档、草稿、终端会话和安装包。

### 验收与回归

隔离 Electron 使用生产底栏、终端面板及原生选择器规则，验证终端隐藏／展开／最大化、侧栏打开／关闭、窄窗口、长菜单与窗口缩放。检查浮层完整落在可视区、底部邻接入口、中心命中菜单而非终端；保留原生节点和事件，关闭／卸载不残留。截图仅作几何证据，不替代真实宿主点击验收。

## R013 字数统计居中

### 问题与方案

右下字数统计文字偏移。宿主 `#footer-word-count` 保留 `padding-bottom:8px`，并继承旧 30px 行高和负上下 margin；工作台已采用紧凑底栏，沿用这些值会使计数框与文字中心错位。

仅规范底栏字数按钮的盒模型：高度跟随底栏可用高度，清除旧负 margin 和单边底部 padding，采用对称水平内边距与 flex 居中，保持当前字号、文字、计数箭头及原生点击事件。源码／差异视图原有隐藏规则优先；不更改统计逻辑或全局 UI 字号。字数详情复用 R012 的浮层几何适配。

### 验收与边界

在终端开关、窄窗口、不同位数与 100%／125% 缩放检查文字及箭头在按钮内容盒内垂直居中、按钮在底栏内容盒内居中；字数点击仍调用原生处理。检查源码状态仍隐藏计数，且清理后恢复宿主样式。

## 验证记录

2026-09-12 已实现底栏浮层几何适配器及字数盒模型。目标回归 `npm run check:ui -- test_workspace_footer.cjs test_workspace_editor_status.cjs test_workspace_document_margin.cjs` 通过：底栏 44 项、编辑器状态 15 项、边距 18 项。新增检查使用生产终端面板与样式、原生选择器及事件语义，包含窗口夹紧、实际指针命中、22px／30px 底栏、不同位数与 100%／125% 缩放；截图已核对图钉弹层邻接底部按钮，字数文字和箭头居中。

沙箱内 Electron 首次启动因 GPU 子进程加载失败，改在正常进程环境运行隔离隐藏窗口后验证；另一次测试因新增长字数用例未恢复旧窄窗夹具而失败，恢复夹具再运行后通过。上述夹具不启动用户 Typora，不等于原生窗口人工验收。共享构建、安装和真实宿主结果由需求台账及反馈记录维护。

2026-09-12 追加原始 Typora ASAR 私有桌面验证，10 项通过。以独立用户目录和项目夹具运行真实宿主、工作台构建与 ConPTY；不切换用户桌面。通过 renderer 鼠标事件触发原生委托处理，验证最近目录条目实际切换宿主目录、图钉收起侧栏后浮动大纲贴近底部且可跳转、字数详情原生开关与文字／箭头居中。浮层中心真实命中菜单节点，所有原始夹具文件摘要、文档正文、修改状态与运行终端 PID 保持。三张原始窗口截图已逐张检查。此证据包含真实宿主事件与命中测试，不声称用户桌面的人工鼠标验收。

原生回归第一轮复现并修复了菜单只剩 5px 的真实问题；中间轮次因夹具未等待侧栏 300ms 布局过渡、缺少隔离历史目录和断言字符串转义而未完成。最终用例在稳定布局取样，并通过已核对的原生 `setting.addRecentFolder` 为独立用户目录添加测试历史后通过。原生截图覆盖当前三处反馈；窄窗、终端最大化／隐藏和多位数字缩放由上述隔离 Electron 回归覆盖。原始用例与截图保存在忽略的 `.cache/native_single_row_compare/footer_native_20260912_e/`。
