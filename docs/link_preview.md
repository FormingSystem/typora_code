# R069 Markdown链接只读预览

2026-09-22用户先授权搜索侧栏链接预览，随后在R069.1明确改为独立的左下预览。以下为当前约定；保留普通链接点击跳转与搜索结果预览。

## 交互与边界

- 渲染正文中的链接文本选择或光标落在链接中，按独立设置更新左下预览；R069.2要求该面板不强制打开功能侧栏，不因悬停联网。右键链接使用明确的左右分屏、上下分屏入口。
- 侧栏和分屏共用只读呈现，本地Markdown渲染正文并定位标题，源码用只读编辑器；分屏提供“打开源文件”进入普通可编辑文件。预览不另建可保存草稿，不改动来源选区和正文。
- HTTP/HTTPS链接在宿主Chromium的隔离iframe中打开，脚本可运行但不授予同源、Node、表单提交、弹窗和顶层导航。站点拒绝内嵌时保留重试及默认浏览器入口；不把网页HTML注入编辑正文，不承诺需登录、Cookie或特殊权限的网站完整可用。
- 本地相对路径以链接所属文件的目录解析，引用式链接使用宿主引用表；不支持的协议、未定义链接、无效目标明确反馈。禁止把网页链接解释成本地文件。
- 独立链接dock与搜索结果预览各自拥有内容；关闭自动链接预览不改变搜索下方的命中预览。
- 选择新链接、关闭自动预览、切换工作区及销毁时移除旧iframe并拒绝迟到结果。分屏目标保持独立，不随正文选区自动替换。

## 职责与实现

链接服务拥有目标解析、文档读取和网络生命周期；现有lookup preview负责安全Markdown/源码呈现，网页采用独立沙箱。链接控制器连接正文选区、右键和独立阅读dock；分屏使用现有core.workspace:split-right/split-down与WorkspaceView注册，按编辑组视图生命周期释放。

菜单沿用共享菜单的13px/24px几何，按钮沿用现有工厂，标签复用已核对的Codicons preview原始图标并显示目标名称；分屏比例由现有编辑组决定。依据见[界面基线](vscode_design_baseline.md)和[拖动分屏设计](drag_and_windows.md)，不新增另一套分屏布局。

## 验收

单元验证相对/绝对/编码路径、文内标题、引用和协议。功能覆盖链接选择、两个方向、重复选择、现有搜索结果切换、只读、打开源文件、失败重试、取消/迟到和清理；本地HTTP夹具验证真实网页脚本、重定向、opaque来源和宿主能力隔离。系统使用隔离Typora、独立临时文档验证真实DOM链接及分屏；记录明暗、窄面板和缩放。按成本执行20次创建/关闭，检查视图和监听器归属。交付验证同一候选安装→检查→卸载→重装，并对实际环境仅做卸载预检。

本地文本沿用2 MiB预览上限；网页加载由Chromium网络栈管理，受站点内嵌策略约束。读取本地已打开文档时优先使用现有文件服务提供的内存正文，预览不写回。正文中的可编辑属性会被去除。

首次实现历史记录：2026-09-22曾完成原搜索侧栏方案的20次分屏检查。本次完整验证、安装状态及未覆盖边界见[交付证据](../enhancements/tests/evidence/link_preview_20260922.json)，不能把静态网页快照等同完整浏览器。

## R069.1 预览独立、主题与阅读锚点（2026-09-22）

本次纠正搜索侧栏作为链接预览前提、文字工具栏占位、只读标签长后缀及缩放后回到初始命中的问题。选中链接默认在当前侧栏下方呈现独立只读预览；关闭自动链接预览只影响该区域，不影响搜索结果预览及显式左右/上下分屏。设置由自有编辑器配置唯一管理，切库、关闭和取消后迟到结果不能恢复旧内容。

预览复用当前文档主题，隔离在 Shadow DOM，保留主题排版规则，只约束预览容器尺寸和只读行为。工具栏复用 Git 打开源文件与刷新图标，分屏标签仅显示文件名，编辑须显式打开源文件。预览缩放保持当前读到的文字，不再重复定位首次命中；查找结果重选仍是显式定位动作。

网页使用宿主 Chromium 的隔离 iframe 加载真实 URL。操作系统默认浏览器没有可供本插件直接嵌入的统一内核接口；不修改 Typora 主进程/ASAR，不绕过网站 CSP/X-Frame-Options。无法嵌入时明确提示并提供默认浏览器入口。iframe 不授予 Node、同源、顶层导航、弹窗、下载或表单权限；保留脚本用于网页排版，页面和宿主隔离。离开目标应中止加载并释放节点。

阅读锚点由共享服务捕获可见文本字符和视口相对位置，布局宽度、字号、边距、分屏变化后按同一字符恢复；不要用固定 scrollTop 或整块顶部代表长段落内的阅读位置。显式搜索/链接跳转由原控制器定位，重排保护不得抢回旧目标。验证覆盖长段落/代码、20轮分屏及缩放、主题、搜索独立开关、失效目标及卸载清理。

上游依据：Electron 官方 Web Embeds 文档，iframe 受站点策略限制；WebContentsView 需要主进程支持，webview 需要 BrowserWindow 显式授权，不能在插件 renderer 中假定存在。

## R073 标签单行与换行（2026-09-22）

新增自有编辑器配置 wrap_tabs，默认 false，对应 VS Code workbench.editor.wrapTabs；开关均保留所有标签及关闭/固定/键盘访问。开启时按编辑组宽度换行，工具区独立保留可用空间；高度不足时回退单行滚动，不能挤没正文。关闭时恢复单行滚动。“更多”菜单继续提供已打开编辑器列表。读到的正文位置沿用 R069.1 共享锚点，不因标签行数变化丢失。

### R073.1 当前组已打开编辑器

原生重排补充：边距、分屏与窗口缩放共用同一字符锚点；显式边距变化经已绑定的重排所有者执行，避免两个锚点相互覆盖。原生`content`重排时通过宿主jQuery停止尚未结束的滚动动画（不跳到旧终点），否则正确恢复后仍会被旧动画拉走。CSS zoom比例不使用舍入整数的offsetHeight推导，避免长文档放大误差。
