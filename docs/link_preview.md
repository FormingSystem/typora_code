# R069 Markdown链接只读预览

2026-09-22用户授权：搜索侧栏打开时，选中Markdown链接即在下方预览目标；右键提供左右和上下分屏预览。本需求不改变普通链接点击跳转、现有搜索结果预览和工作台布局。

## 交互与边界

- 渲染正文中的链接文本选择或光标落在链接中，搜索侧栏可见时更新预览；不因悬停联网，不自动打开侧栏。右键链接使用明确的左右分屏、上下分屏入口。
- 侧栏和分屏共用只读呈现，本地Markdown渲染正文并定位标题，源码用只读编辑器；分屏提供“打开源文件”进入普通可编辑文件。预览不另建可保存草稿，不改动来源选区和正文。
- HTTP/HTTPS链接联网获取网页文档，在禁止脚本、表单、导航和宿主能力的沙箱内阅读；样式与图片按最终网页地址解析。网页属于只读文档快照，不承诺登录页、需JavaScript应用的完整运行；失败显示原因和重试，并提供系统浏览器入口。不会把网络HTML注入宿主编辑器。
- 本地相对路径以链接所属文件的目录解析，引用式链接使用宿主引用表；不支持的协议、未定义链接、无效目标明确反馈。禁止把网页链接解释成本地文件。
- 搜索排队、运行中或失败时，后来选中的链接继续拥有下方预览；搜索仍可生成结果，但不自动覆盖链接。明确输入新查询或选择结果才切回搜索预览。
- 选择新链接、关闭/隐藏预览、切换工作区及销毁时取消网络请求并拒绝迟到结果。分屏目标保持独立，不随正文选区自动替换。

## 职责与实现

链接服务拥有目标解析、文档读取和网络生命周期；现有lookup preview负责安全Markdown/源码呈现，网页采用独立沙箱。链接控制器连接正文选区、右键和搜索侧栏；分屏使用现有core.workspace:split-right/split-down与WorkspaceView注册，按编辑组视图生命周期释放。

菜单沿用共享菜单的13px/24px几何，按钮沿用现有工厂，标签复用已核对的Codicons preview原始图标并显示目标名称；分屏比例由现有编辑组决定。依据见[界面基线](vscode_design_baseline.md)和[拖动分屏设计](drag_and_windows.md)，不新增另一套分屏布局。

## 验收

单元验证相对/绝对/编码路径、文内标题、引用和协议。功能覆盖链接选择、两个方向、重复选择、现有搜索结果切换、只读、打开源文件、失败重试、取消/迟到和清理；本地HTTP夹具验证重定向、内容限制、超时、脚本与表单隔离。系统使用隔离Typora、独立临时文档验证真实DOM链接及分屏；记录明暗、窄面板和缩放。按成本执行20次创建/关闭，检查视图和监听器归属。交付验证同一候选安装→检查→卸载→重装，并对实际环境仅做卸载预检。

本地文本和网页文档上限2 MiB，网页请求总期限15秒、最多5次重定向；超限和失败留在预览内，可重新加载。读取本地已打开文档时优先使用现有文件服务提供的内存正文，预览不写回。正文中的可编辑属性会被去除。

2026-09-22实现已接入；真实宿主20次分屏与70项检查通过。本次完整验证、安装状态及未覆盖边界见[交付证据](../enhancements/tests/evidence/link_preview_20260922.json)，不能把静态网页快照等同完整浏览器。
