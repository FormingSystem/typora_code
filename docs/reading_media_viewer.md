# 图片与图表放大查看

## R031 图片放大入口

2026-09-13，用户要求图片像现有 Mermaid 一样提供放大观看按钮。原生 Markdown 正文及 Git 历史阅读中已经显示的图片增加“全屏查看”按钮，共用图表查看器。搜索预览目前过滤图片，此次不改变其资源加载规则；未加载或损坏的图片不提供无效入口。

用户随后明确单击与选中图片有关，因此只增加图片本身的左键双击放大，单击保留宿主选中；双击正文文字、带修饰键的链接操作不接管。按钮和图片双击共用同一打开路径。

2026-09-13追加反馈明确：入口放在图像外侧右上方，悬停时覆盖显示；单独预留一行会拉大正文与图片距离。本次取消先前的工具行占位，正文外的固定阅读层按原图矩形定位按钮，默认隐藏，悬停或键盘聚焦时显示；不插入正文节点、不添加图片包装、不改变 margin/padding、行高或图片尺寸。挂载、悬停、卸载均保持前后段落和图片的原有间距。

`reading_media_entry` 唯一管理按钮层、可见范围裁剪与事件。沿用32px按钮、16px图标、左右8px留白、外侧8px间隙；这些数值仅用于浮层，不计入正文高度。图片与 Mermaid 按已显示的原图／预览矩形定位，随原图滚动；入口滚出可见范围后隐藏，不吸附到正在阅读的图片中段。鼠标从原图经过8px间隙进入按钮时保持显示，移出整个区域隐藏；桥接命中只在显示时生效，宽度限于按钮及左右留白，不拦截同一行的正文。宽度不足160px仅显示图标，不足48px不展示入口，图片双击仍有效。加载失败、来源替换或销毁释放对应入口。原生 Mermaid 的横向滚动壳带有 overflow-y:hidden，浮层允许越过其未滚动的上边界；来源上沿被裁剪或滚动后隐藏。真正的阅读滚动区仍约束整个入口，不能越过顶栏或底栏。

## 交互与状态归属

`reading_media_viewer` 唯一管理窗口内的查看器、缩放、位移、键盘焦点和资源释放。Mermaid 继续复制已渲染 SVG 并重写内部 ID，图片只取已加载图片的实际资源地址和自然尺寸，以独立 img 显示，不修改原图颜色、大小或文件。原生图表与 `reading_image_viewer` 只提供来源和打开内容，统一入口负责浮层与按钮几何；两者不再各自设置 top/right 或悬停样式。

沿用现有 Mermaid 的六项控制：缩小、放大、适应宽度、适应屏幕、100%、退出全屏；Ctrl+滚轮围绕指针缩放、左键拖动、双击画布适应屏幕、Esc 退出。图片打开时先完整适应屏幕且不放大小图，100%恢复自然尺寸；图表保持既有100%初始状态。手动缩放沿用1.25步进、最大600%，适应超大图片时允许低于20%，保证完整查看。查看器使用当前阅读背景，图片本身不进行主题反色。

窄窗口工具栏换行，画布跟随剩余空间；Tab限制在查看器内，退出按 [R032](workspace_interaction.md#r032-esc退出与原操作恢复) 恢复打开前的编辑焦点／选区；键盘从入口启动时归还入口，并保持阅读滚动。Ctrl快捷键不穿透成窗口缩放或正文编辑。切换来源、来源资源变更、阅读器销毁或增强卸载时关闭查看器；异步图片加载失败给出可关闭的错误提示，不保留无效缩放按钮。

## 设计依据与边界

基线为本仓库 a21af8d 的 `typora_enhancements.ts` / `.css` 中实际 Mermaid 控件及缩放算法：按钮32px、图标16px、控件间距6px、画布水平20px、适应屏幕0.88留白、适应宽度0.92。本次提取共享查看器，保持已有控制语义；按钮复用公共交互默认4px圆角和已固定的Codicons `screen-full/add/remove/close`，不复制另一套悬停颜色。只读查看不下载文件、不导出、不编辑图片，单击图片、链接和原生编辑操作仍由宿主管理。

## 验收

在隔离 Electron 中用 Chromium 指针与键盘验证按钮首次点击、图片单击选中／双击放大、缩放中心、拖动、适应、100%、Tab/Esc、滚动保持、明暗主题、窄窗口与缩放；验证大图、小图、同段多图、加载中/失败、动态替换、来源变化、隐藏、卸载重载和Shadow DOM历史图片。回归Mermaid原入口和现有窗口缩放、阅读生命周期。原生Typora私有实例核对图片实际DOM、Markdown及dirty状态不变、入口与画布布局；原生DOM/API激活证据不冒充物理鼠标操作。构建、完整检查和安装结果以本轮反馈记录为准。

本次入口回归同时覆盖图片与 Mermaid：比较挂载前后、悬停和卸载后的原图、前后段落矩形以及正文 DOM，确保没有新增行或排版位移；入口下沿与图像上沿保留8px间隙，滚动到图片中段不吸附。覆盖100%／125%缩放、窄窗、明暗、链接图片、多图、小图、加载失败、Shadow DOM及销毁恢复。隔离原生检查编辑与撤销、Markdown和dirty状态、同一原图节点及属性不变。
