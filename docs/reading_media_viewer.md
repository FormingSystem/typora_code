# 图片与图表放大查看

## R031 图片放大入口

2026-09-13，用户要求图片像现有 Mermaid 一样提供放大观看按钮。原生 Markdown 正文及 Git 历史阅读中已经显示的图片增加“全屏查看”按钮，共用图表查看器。搜索预览目前过滤图片，此次不改变其资源加载规则；未加载或损坏的图片不提供无效入口。

用户随后明确单击与选中图片有关，因此只增加图片本身的左键双击放大，单击保留宿主选中；双击正文文字、带修饰键的链接操作不接管。按钮和图片双击共用同一打开路径。

2026-09-13追加反馈明确：入口放在图像外侧右上方，悬停时覆盖显示；单独预留一行会拉大正文与图片距离。本次取消先前的工具行占位，正文外的固定阅读层按原图矩形定位按钮，默认隐藏，悬停或键盘聚焦时显示；不插入正文节点、不添加图片包装、不改变 margin/padding、行高或图片尺寸。挂载、悬停、卸载均保持前后段落和图片的原有间距。

`reading_media_entry` 唯一管理按钮层、可见范围裁剪与事件。沿用32px按钮、16px图标、左右8px留白、外侧8px间隙；这些数值仅用于浮层，不计入正文高度。图片与 Mermaid 按已显示的原图／预览矩形定位，随原图滚动；入口滚出可见范围后隐藏，不吸附到正在阅读的图片中段。鼠标从原图经过8px间隙进入按钮时保持显示，移出整个区域隐藏；桥接命中只在显示时生效，宽度限于按钮及左右留白，不拦截同一行的正文。宽度不足160px仅显示图标，不足48px不展示入口，图片双击仍有效。加载失败、来源替换或销毁释放对应入口。原生 Mermaid 的横向滚动壳带有 overflow-y:hidden，浮层允许越过其未滚动的上边界；来源上沿被裁剪或滚动后隐藏。真正的阅读滚动区仍约束整个入口，不能越过顶栏或底栏。

## 交互与状态归属

`reading_media_viewer` 唯一管理窗口内的查看器、缩放、位移、键盘焦点和资源释放。Mermaid 继续复制已渲染 SVG 并重写内部 ID，图片只取已加载图片的实际资源地址和自然尺寸，以独立 img 显示，不修改原图颜色、大小或文件。原生图表与 `reading_image_viewer` 只提供来源和打开内容，统一入口负责浮层与按钮几何；两者不再各自设置 top/right 或悬停样式。

沿用现有 Mermaid 的六项控制：缩小、放大、适应宽度、适应屏幕、100%、退出全屏；Ctrl+滚轮围绕指针缩放、左键拖动、双击画布适应屏幕、Esc 退出。图片打开时先完整适应屏幕且不放大小图，100%恢复自然尺寸；图表保持既有100%初始状态。手动缩放沿用1.25步进、最大600%，适应超大图片时允许低于20%，保证完整查看。查看器使用当前阅读背景，图片本身不进行主题反色。

窄窗口工具栏换行，画布跟随剩余空间；Tab限制在查看器内，退出按 [R032](workspace_interaction.md#r032-esc退出与原操作恢复) 恢复打开前的编辑焦点／选区；键盘从入口启动时归还入口，并保持阅读滚动。Ctrl快捷键不穿透成窗口缩放或正文编辑。切换来源、来源资源变更、阅读器销毁或增强卸载时关闭查看器；异步图片加载失败给出可关闭的错误提示，不保留无效缩放按钮。

## 设计依据与边界

基线为本仓库 a21af8d 的 `typora_enhancements.ts` / `.css` 中实际 Mermaid 控件及缩放算法：按钮32px、图标16px、控件间距6px、画布水平20px、适应屏幕0.88留白、适应宽度0.92。本次提取共享查看器，保持已有控制语义；按钮复用公共交互默认4px圆角和已固定的Codicons `screen-full/add/remove/close`，不复制另一套悬停颜色。只读查看不下载文件、不导出、不编辑图片，单击图片、链接和原生编辑操作仍由宿主管理。

本次入口回归同时覆盖图片与 Mermaid：比较挂载前后、悬停和卸载后的原图、前后段落矩形以及正文 DOM，确保没有新增行或排版位移；入口下沿与图像上沿保留8px间隙，滚动到图片中段不吸附。覆盖100%／125%缩放、窄窗、明暗、链接图片、多图、小图、加载失败、Shadow DOM及销毁恢复。隔离原生检查编辑与撤销、Markdown和dirty状态、同一原图节点及属性不变。

## R031 悬停入口的不透明底色

2026-09-13，用户指出全屏查看按钮已在移出后隐藏，显示时应使用不透明底色。原入口本身引用宿主 `--bg-color`，但公共action悬停规则用带alpha的工具栏颜色覆盖了背景，导致其下方的图片或文字透过按钮。

在唯一入口样式 `reading_media_entry.css` 中声明公共交互的局部hover背景和前景，分别引用原宿主阅读背景、正文文字色；图片和Mermaid同时生效，不增加另一套主题识别或事件。沿用原生Light／Night不透明阅读底色及既有按钮尺寸、边框、图标、圆角，普通显现、按钮悬停和键盘焦点均保留实体背景。公共层继续管理hover／焦点绘制，显隐仍归现有入口状态，不改变外侧右上定位、命中桥、默认隐藏或正文零占位。

回归以实际鼠标移入媒体、移至按钮、再移出为一个完整周期，覆盖图片和Mermaid、明暗主题。显示时按钮opacity与背景alpha均为1，文字和图标对比可读；移出且无键盘焦点时隐藏，不新增正文行或改变图片、段落几何。继续执行按钮打开、图片单击选中／双击放大、Esc焦点恢复、窄窗和卸载回归。损坏资源与来源消失仍由原有生命周期隐藏入口，不新增失败状态。

## R031.2 图片原始尺寸与全局对齐（2026-10-02）

图片默认100%优先原始尺寸，大图缩小至编辑区可用宽度；设置提供20%–600%全局缩放和“适应宽度”模式。悬停工具条提供滑条、100%、适应宽度、对齐与全屏入口。滑条只改变全局显示比例，输入时内存预览，结束手势保存一次；Esc、失焦、取消或保存失败恢复已保存状态。全屏查看器缩放独立。

用户最新补充覆盖此前仅全局的约定：对齐同时支持全局默认和单张图片覆盖。设置管理全局左/中/右默认；右键及悬停菜单分列“此图片对齐”“全局图片对齐”。单图优先，选择“跟随全局”删除该覆盖。单图操作复用已核对的Typora1.14.10 imgEdit.addStyle(wrapper,"margin",value)，使用原生撤销和保存；首次设置将Markdown图片转为HTML图片，保留相对链接、alt及其他样式。只读历史阅读器禁用单图修改，切文档/旧节点失效拒绝操作。全局设置不写正文。

原始Typora1.14.10 base.css仅设置max-width:100%并居中独占段落的图片；固定VS Code6807068的extensions/markdown-language-features/media/markdown.css:306同样限制最大宽高。原生基线普通64×40图片未拉伸，显式width:100%的HTML图片复现铺满；不能把包装节点100%宽度当作图片尺寸缺陷。本次明确以全局显示策略覆盖width/height，不改图片文件或源属性；已有原生单图zoom优先保留。

reading_image_settings唯一拥有持久配置及滑条临时状态；reading_image_layout使用阅读器外部样式表显示自然尺寸和全局对齐；reading_image_native集中适配单图修改；菜单、统一设置和悬停控件调用同一所有者。共享媒体浮层在正文外组织控件，沿用32px按钮、16px图标、4px公共交互圆角；滑条宽度沿用搜索预览92px，比例上下限沿用媒体查看器。窄窗口换行，图片仍可见时工具条可贴阅读视口上边缘，覆盖此前图片中段不吸附约定；Mermaid和代码复制保留原布局。销毁释放样式、控件、预览手势和菜单。

原生正文及允许图片加载的历史阅读器共享布局。搜索/链接预览继续沿用既有图片资源政策，不扩大加载范围。验证包括全局菜单/设置/滑条、失败取消、单图原生撤销/重做/保存/重开、明暗与缩放、窄窗、Shadow阅读器、20/100/1000图片生命周期和共享媒体/代码复制回归。实际执行、失败与未测边界见本轮反馈记录；安装和卸载必须针对最终候选。

### R031.2 数字比例与宽度基准修订（2026-10-02）

用户取消滑条，改为减号、百分比数字框、加号；左右按钮和上下方向键每次5%，保留20%–600%的现有配置范围。100%基准为原图尺寸与当前图片所在编辑区可用宽度的较小值；实际宽度为基准乘比例，并始终封顶到可用宽度。比如2000px原图/800px编辑区，50%为400px、100%为800px、150%仍为800px。小图64px在同一区域150%为96px。容器改变时CSS百分比自动重算，不新增全局观察器。显式原生单图zoom继续优先。

数字输入合法时临时预览；回车或失焦提交，Esc恢复；空值、非数值及超范围不写设置、不改变正文，失焦恢复已保存比例。步进从合法草稿或当前值计算，夹紧现有边界并一次保存。输入草稿不能被同一预览通知覆盖。共享设置拥有临时值/持久值，控件仅拥有文本草稿和焦点；所有图片沿用同一全局比例，单图对齐语义不变。保存失败恢复原显示。

图标使用既有官方Codicons add/remove，尺寸复用媒体32px按钮/16px图标；数字框沿用固定VS Code6807068的src/vs/base/browser/ui/inputbox/inputBox.css（继承字体、4px 6px内边距、border-box），宽度以百分比内容安排，不新增普通按钮悬停规则。验收覆盖大小图比例、尺寸上限、容器变化、真实键盘/按钮、明暗与窄框、主题和正文保护、单图原生缩放、销毁与本机安装/隔离卸载。本修订替代上文滑条交互及相对原图后截断的旧算法，不代表R071.7黑屏修复。
