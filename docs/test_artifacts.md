# R077 测试临时产物生命周期

2026-09-25：原生验收每次复制整个宿主，安装用例复制发行文件并产生多轮隔离备份；运行器仅终止进程，未回收载荷。失败用例和UI临时目录也会长期保留。本机曾累计约226GiB此类目录，用户已手动清理。新规则只管理测试生成物，真实Typora安装备份、用户文档、主题及配置不属于自动清理范围。

## 所有权和生命周期

`enhancements/scripts/manage_test_artifacts.py`集中登记与回收。原生用例继续在`.cache/issue_tracking/native/<随机ID>`留证；完整`npm run check`、安装、卸载及统一UI运行器使用`.cache/test_runs/<随机ID>/work`作为临时根，证据存于同级`evidence`。不再默认把这些大型载荷留在系统TEMP。目录在开始分配时即写标记，包含类型、创建时间、所有者进程及其启动身份；子进程纳入租约，避免PID复用误判。

UI与完整检查会保留自定义名称的JSON测量结果；原生和安装用例保留检查结果及日志。成功、失败、超时都先保留结果JSON、日志和截图，再回收复制的宿主、测试工作区、隔离配置与安装备份。清理失败记录原因，不掩盖原测试错误；下次测试启动回收超过24小时、所有者及已登记子进程均结束的有标记载荷。只扫描这两个专属根目录，不按文件年龄或名字删除系统临时目录，更不触碰真实恢复备份。无标记旧目录不自动收养。

跨两次进程启动的会话测试由外层运行器持有目录，阶段之间明确保留，最后统一结束。调试可设`TYPORA_KEEP_TEST_WORK=1`暂留载荷；下次过期回收仍受进程存活约束。人工回收入口默认只列计划，`python enhancements/scripts/manage_test_artifacts.py sweep --apply`才处理符合条件的目录。

边界校验包括固定根、随机ID、固定载荷名及禁止符号链接/junction穿越；清理前复查进程与路径。登记与证据留存失败时不删除载荷。测试目录不能承载唯一真实用户数据。体积和时间规则不用于限制用户文件内容。

## 验收

验证正常/失败清理、日志/截图保留、无标记拒绝、路径越界和链接拒绝、活动进程跳过、过期崩溃目录回收及重复结束。真实原生验收后仅留结果/截图，Windows5.1安装与卸载回归后测试载荷移除；UI测试包括超时清理。保留平台和端口替身边界，不能把清理回执等同于功能通过。

公开检查入口由`run_test_command.py`持有整套检查的临时根；`check:core`仅为内部命令。新测试通过这些运行器使用系统临时目录API即可落入专属工作区，直接单独执行旧脚本不会自动获得外层清理。文件锁串行化登记与回收，进程退出自动释放锁；只读Git对象按已验证边界处理，短暂文件占用有限重试，失败留现场及cleanup_error。
