## Interaction and responsibilities

Comparison identity, Git reading, errors and refresh continue to be owned by the existing Git document service; Monaco's asynchronous difference results are the sole source of change scope. Rendering view does not read the working tree, save files, or start a second Git scan on its own. Map complete Markdown blocks to source code lines; unchanged blocks serve as left-right alignment anchors, changed blocks are left red and right green, new or deleted blocks leave corresponding empty spaces on the side. Titles, lists, tables, citations, and fences maintain structure; besides color, deletion/new addition semantic tags are displayed. Toolbar front change and F7 positioning current view, open original file and entire file actions are retained. Selection staging/undo only operate on the source code side, rendering state explicitly disables; search switches to source code positioning, cannot operate on hidden selections.

Shared preview theme extraction and code/chart rendering, Shadow DOM isolates native editing enhancements. History HTML purification, links only display text and target, do not automatically open external pages; images display alternative text and address, avoid using the current image to impersonate historical images. Front Matter and invisible definition changes display source code blocks, prevent losing changes. Modifications only to syntax formatting still mark the block. In this stage, block-level coloring is provided, no commitment to word-level coloring, complete Typora math/HTML extensions, or historical attachment reading.

A single comparison shares a scrolling container, paired blocks align to the higher side; narrow viewport still retains left and right two columns. Switching modes saves individual scrolling; refresh/switch settings/closing use intergenerational rejection of late-rendering and release chart resources. Difference calculation not yet complete displays waiting; starting from 2026-09-25, according to [R075 capacity rules](resource_capacity.en.md), cancel the interception of 1MiB and 10000 lexer tokens on both sides, users can cancel processing, actual exceptions are fed back through the original error channel. Formatting and DOM construction let go of threads in batches, do not expand the memory path of the previous large repository.

## R034.7 Markdown semantic diff range

Block source scope does not include trailing blank lines, zero-length insertions are handled at line boundaries to avoid adding a new paragraph that affects the previous unchanged heading. The same block is used as an anchor; tables and lists further compare rows/items, preserving semantic containers, and tables only color actual changed cells. New/deleted items maintain clear additions/deletions. Changes in link targets, formatting, and definitions should not be considered as no change simply because the visible text is the same. Complex HTML or structures that cannot be reliably split retain block-level differences and do not claim full Markdown semantic equivalence. Overview and before/after difference jumps use actual change nodes, and cannot count areas with no changes.

Regression includes headings added after, EOF/blank lines/CRLF, repeated blocks, table cell/row insertions/deletions, list insertions/deletions, code/link definitions, source code and rendering back-and-forth scrolling positioning, 20 rapid switches, different widths/themes; native host and installation/uninstallation are separately recorded.
