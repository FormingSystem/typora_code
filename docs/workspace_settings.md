# R072 三层设置与统一自有配置

2026-09-22用户要求：Typora原生、社区插件、TyporaCode自有功能分为三层；自有功能统一一层管理，不能在多个配置入口维护互不一致的副本。

## 交互与归属

对照VS Code设置编辑器的搜索、分类、配置值和恢复默认交互，按R072.2在唯一浮动窗口中打开设置；背景资源管理器不占用设置内容宽度，关闭后回到原工作台。设置页只显示自有分类，原生偏好和社区设置从分类区直接打开。Typora原生层调用已核实的宿主偏好接口；社区插件层保留插件原始SettingTab及其持久化，不转换插件字段或注入本工程默认值。TyporaCode层集中展示现有功能配置，包括编辑器、资源管理器/保存、面包屑、顶栏、差异编辑器、终端、Git及SSH。

自有配置使用统一注册表描述分类、默认值、作用域、字段和读写接口。注册表不存第二份配置，各领域服务仍拥有校验、持久化与生效订阅。切换设置分类不创建第二套服务；旧快捷入口与统一页调用同一保存接口。Git按仓库、语言服务按工作区、普通显示按用户作用域，界面显示实际目标；目标切换后不能把旧表单应用到新目录。

搜索同时匹配中文标题和配置键；修改经现有校验成功后生效，失败保留输入并显示原因。单项重置仅影响该项，不能覆盖其他配置。复杂对象用明确JSON输入并校验，密码和私钥内容不作为可编辑JSON存储；SSH端口、密钥、代理和主机信任继续由OpenSSH配置管理。缺失的注册服务不伪造可保存表单。

## 验收

验证三类入口、搜索、修改/重置、旧入口一致性、坏值和持久化失败、切目录的旧目标保护、注册/注销与关闭重开清理；默认/明暗/窄编辑组/键盘。实际原生偏好与插件SettingTab独立验证，不能拿模拟API调用当作原生设置页验收。构建和安装/卸载按统一交付要求执行。

历史状态：2026.09.22.10构建、关联UI/原生及安装卸载验证通过，已本机安装；用户窗口未重启。完整SSH工作区行为仍由R070跟踪，统一设置页不代表所有远程能力已实现。

- 固定提交`645f29cc3176500b4b5762ba887cf2a7f0ffdf2c`的`src/vs/workbench/contrib/preferences/browser/media/settingsEditor2.css`：最大内容宽1400px，内容水平24px，一级分组标题26px，标签13px与7px/6.5px垂直、8px水平内边距，下拉26px与2px/6px内边距。本页采用这些基础值，窄组与三类所有者入口使用现有编辑组布局，不宣称所有尺寸/功能已像素等价。
- 当前自有层接入编辑器、资源管理器/保存、顶栏、面包屑、差异、语言服务、终端、Git和SSH已有配置。复杂JSON沿用原校验；未新增未实现功能的虚假开关。旧快捷配置入口保留并共用所有者，不执行破坏性存储迁移。

交付证据见[本次验证](../enhancements/tests/evidence/settings_ssh_20260922.json)。本轮不重写原生偏好/插件字段；设置页提供实际所有者入口，原有单项配置仍共用业务存储。

## R072.1 用户纠正：隔离所有者，不复制导航（2026-09-22）

本节替代上文“三类顶部页签”设计。齿轮菜单只提供一个设置入口及扩展管理，不再重复原生/社区/自有三个菜单；自有设置页按VS Code搜索和分类组织，原生偏好及社区设置由分类中的明确入口直接打开原始页面，不提供只有跳转按钮的空页面。自有UI不能继承Markdown标题样式；插件SettingTab不得放进会重写输入、标题和按钮的工作台对话框内容区。下载官方社区发行包在独立宿主比较其真实设置结构、样式和保存，并维护适配边界；原生和第三方配置仍由各自所有者保存。

设置齿轮以本次明确授权采用固定VS Code Codicons `settings-gear`，覆盖此前保留fa-cog字形的约定；活动栏槽位不变。Ctrl+,统一进入自有设置，文件菜单的Typora偏好入口保留原生命令。验收增加齿轮菜单去重、导航无重复空页、原生/插件直接打开、主题标题不泄漏和插件原始字段/交互/存储独立。

社区配置容器对照官方2.10.23的`settings-modal.scss`、`_sidebar-nav.scss`与`modal.scss`：90vw×85vh、.875rem字号、1rem外内边距、10rem分类及.75rem分类字号。仅适配挂载/共享退出栈与右上关闭；原始SettingTab节点不重新生成，字段样式不套用工作台`.git-graph-dialog`或统一交互层。

R072.1本次交付证据：[设置隔离与双机合并验证](../enhancements/tests/evidence/settings_isolation_merge_20260922.json)。

## R072.2 浮动设置窗口（2026-09-22）

用户最新截图指定 VS Code Modal Editor，替代先前自有设置作为普通编辑器标签的呈现方式。配置仍经同一注册表与各领域服务读写；齿轮和 Ctrl+,复用唯一浮动窗口，背景资源管理器保持原状态而不参与设置宽度。右上提供最大化/还原和关闭，Esc关闭并恢复进入前焦点；原生偏好和社区 SettingTab 继续独立。不得通过隐藏文件树、重建编辑组或改写正文实现。

基线：固定 VS Code 1.137.0（645f29cc） 的 modalEditorPart.ts：默认最大1400×900、最小400×300、最大化外边距16px、头部33px。沿用共同对话框退出栈/焦点保护，自有设置专属布局不覆盖第三方弹窗。验收含短窗口、窄窗口、缩放、默认/最大化、重复入口、关闭焦点与配置失败保持；不声称移植全部 VS Code Modal Editor 拖动/窗口迁移能力。

## R072.3 右侧托管原始设置页面

2026-09-23用户明确：点击分类区的社区设置后，页面被挡在统一设置后面；Typora偏好和社区配置都应显示在右侧内容区域。本节替代R072.1/R072.2中“直接另开页面”的呈现约定，仍保持三类配置的所有者独立。

统一窗口保留搜索、左侧分类、最大化和关闭。选中原生或社区分类后，右侧显示该所有者真实页面，选中自有分类返回原表单。社区使用真实SettingTab节点，show/hide/load/unload和持久化仍归社区适配器；不生成映射表单。Typora使用核实的`ClientCommand.showPreferencePanel`、`File.megaMenu.closePreferencePanel`和现有`#uni-preference-panel`内原生webview，不克隆、销毁或重建原生配置页面。

外部页面由一个共享几何托管器限定在右侧矩形，保留在工作台表单CSS之外的独立节点；该区域登记到统一弹窗的内部命中与焦点范围，避免被判为点到遮罩。切换、关闭、窗口销毁时释放几何观察器和临时属性，原生节点恢复原位置规则；社区解除显示而不卸载插件。原生页面自己的关闭返回自有设置。插件禁用或卸载清除其活动SettingTab但保留可用列表，不遗留后方弹窗。打开插件市场则先退出设置窗口再展示真实管理页。

原生接口依据本机Typora1.14.10原始`resources/appsrc/window/frame.js`的偏好实现：首次创建webview，后续reloadData；关闭恢复临时侧栏并移除show-preference-panel。几何沿用R072.2固定VS Code Modal Editor的窗口和右侧布局；社区内部沿用已核对的官方2.10.23设置样式。本次只改变承载区域，不把自有表单样式套到插件控件，也不修改原生偏好字段。

加载不可用显示明确原因，仍可切回其他分类；快速切换不能让迟到页面重新出现。验收包含真实点击命中、Tab/Esc和关闭、默认/最大化/窄宽/缩放、20轮切换清理、实际社区设置编辑保存重开、原生webview渲染及独立入口恢复，并核对正文和配置未受无关变更。

原生退出会异步恢复正文焦点；统一设置保留模态窗口，不把该宿主失焦当作用户关闭。仍由右上关闭、Esc和遮罩操作退出。2026-09-23当次构建、271设置断言、210原生检查及同候选安装/卸载通过，详情见[交付证据](../enhancements/tests/evidence/settings_owner_20260923.json)。
