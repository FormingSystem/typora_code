# 左键拖动与独立窗口

标签页、左侧活动栏工具和工作台已有的对象排序控件共用同一套拖动会话。左键按住后移动超过 6 CSS px 才进入拖动态，轻微手抖仍按普通点击处理。拖动使用对象现有图标和名称作为跟随预览，来源半透明，落点显示插入线或目标编辑组；松开才提交排序。Esc、失焦、指针取消、来源被移除及工作台卸载都取消本次拖动并清理预览。

侧栏工具按落点调整顺序，沿用原有顺序持久化；没有跨栏移动或变成文件标签。分界线、文字选区和缩略图仍使用各自的拉伸、选择及滚动语义。此修复统一的是已有对象的“按住—拖动—松开”动作，并非给所有控件新增移动功能。

## 标签排序与跨组移动

标签可在同组排序，也可移到另一个编辑组；落点优先采用实际编辑组。排序同时更新布局模型与 DOM，后续快捷键切换遵循新顺序。标签过多时，拖至标签栏边缘会自动横向滚动。源标签通过所属组与叶子对象共同定位，同一路径在多个组打开时不会误取另一组；目标组已有同一路径时拒绝重复移入。

拖动不会提前切换活动文档或关闭来源。点击关闭按钮、菜单、输入框以及文本选择均不会误触发标签拖动。

## 拖至新的 Typora 窗口

真实文件标签离开原编辑组至少 30 CSS px、没有落入其他编辑组或侧栏／顶栏等工具区域时，松开鼠标会请求新 Typora 窗口。在新窗口确认文档、格式与位置恢复后，来源再次核对捕获时的内容、磁盘基线和标签身份，一致才移除原标签。

这个距离是本产品针对用户“拖出一定距离”的明确规则，不是 VS Code 的内部阈值。VS Code 的固定实现默认只在当前窗口之外释放时创建辅助窗口；其行为参考见 [VS Code 自定义布局](https://code.visualstudio.com/docs/configure/custom-layout)。本实现使用 Typora 自己的窗口，窗口初始几何由宿主决定，不提供 VS Code 辅助窗口的全部功能。

原生入口为经 Typora 1.14.9 核对的 `JSBridge.invoke("app.openFile", null, {mountFolder, anchor})`。随机 UUID 放在新窗初始化锚点中，双方通过同名内存频道交接快照；普通新窗口和已有文档窗口不会订阅或接收。没有修改 ASAR，也不把草稿写成临时文件。文件系统路径只在运行时用于实际打开和身份验证，不写入项目配置。

### 文档与草稿边界

| 情况 | 行为 |
| --- | --- |
| 已保存 Markdown，包括后台预览标签 | 新窗打开原文件并恢复阅读位置；确认后移除来源标签 |
| 已保存或未保存的源码标签 | 交接当前正文、语言、编码／BOM／换行设置、选区和滚动状态，保留磁盘保存基线；成功后移除来源 |
| 未保存的原生 Markdown，关闭自动保存 | 新窗恢复草稿并保持未保存状态，来源保留草稿副本；不冒宿主关闭过程自动保存的风险 |
| 未保存的原生 Markdown，开启自动保存 | 在创建新窗前提示并保留原标签；先保存草稿或处理自动保存设置后再拖动 |
| Untitled、目录、符号链接、Git 历史／diff、Graph、终端等虚拟标签 | 不作为普通文档移交；未命名文档先保存 |
| 来源有后续编辑、文件在磁盘改变、目标被用户操作、超时／失败／取消 | 保留来源，拒绝覆盖目标当前内容；已成功恢复的副本不会清空 |

源文件读取上限为 16 MiB，超大草稿也会拒绝移交。读取使用异步句柄、分块读取和异步摘要；捕获与双窗交接分别有 25 秒超时，取消后不再启动排队的导航。若源窗口另有未保存的原生 Markdown，也会保留来源标签，避免关闭过程间接触发宿主保存。

源码恢复后的显式保存仍执行已有冲突检查；不会把来源的磁盘基线替换成未经核对的新内容。旧窗口的完整撤销历史不跨进程迁移，接收窗口建立新的编辑历史。两个窗口的后续编辑独立，不做实时协同。

## 验证入口

在 `enhancements/` 执行：

```sh
npm run check:ui -- test_workspace_drag.cjs test_workspace_activity.cjs test_workspace_detached_window.cjs test_workspace_document_transfer.cjs
```

拖动目标用真实指针事件与工作区模型验证阈值、跟随预览、排序、跨组、外置宿主正文、取消和清理。窗口通信目标用两个隔离 Electron renderer 验证随机频道、确认、超时、迟到消息及取消；文档目标使用真实 Monaco 与临时文件验证格式、空草稿、外部冲突、显式保存和磁盘字节不变。原生 Typora 的最终集成结果单独记在 [反馈复查记录](feedback_review.md)，不以这些夹具代替实窗结果。
